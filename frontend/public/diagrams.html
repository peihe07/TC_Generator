1為什麼是 GUI + AI

AI 負責生成、人負責審查、固定動作走 GUI。

為什麼需要 AI
生成是這個專案的核心
把一行 requirement 轉成 Pre-Cond / Input / Procedure / Expected Result 需要理解語意，不是填 template。沒有 AI 生成，整個系統只是一個 Excel 解析器。
為什麼是 GUI
Review 必須能逐列看見
AI 產出不能直接交付，每筆 TC 都得有人逐列確認。在 chat 裡 accept / reject 200 筆 TC 不可行，把流程外化成畫面才看得到狀態、改得動。
為什麼不全交給 Agent
把固定流程做成按鈕更便宜
Upload、Configure、Generate、Export 這些是固定動作，做成 GUI 按鈕直接打 Backend，不需要 LLM 來「理解你想做什麼」。token 只花在真正的生成上，不花在意圖解析。

2主流程

五個步驟，五個視窗，按「下一步」自動切換。

Step 1
Upload
拖入 TC workbook，建立 Job ID。
< 30s $0
Step 2
Configure
分組、spec matching、選 model。
1–2 min < $0.01
Step 3
Generate
透過 SSE 串流逐筆產出 TC，並顯示累積進度與成本。
2–5 min ≈ $0.10
Step 4
Review
逐筆 Accept / Edit / Regenerate / Re-run。
5–15 min 依重生次數
Step 5
Export
寫回 Excel、TC ID 重編、下載。
< 10s $0

3每步驟：User vs Backend

左欄是 User 在 GUI 上的動作，右欄是觸發的 API。

Step 1 · Upload

User

  • 拖入 TC workbook（*_SWQT_{TestGroup}_YYYYMMDD.xlsx）
  • 選填：SYS1 spec、補充 spec、framework.json

Backend

  • 解析 workbook、建立 Job ID、保存原檔以供日後寫回
  • 偵測同 Requirement ID 的 sibling rows，標註以利 generate 階段參考

Step 2 · Configure

User

  • Grouping：Fill Blank / Regroup All → Apply
  • Spec Matching：檢查 preview，必要時覆寫
  • Options：選 model（gpt-5 / gpt-5.4）與批次大小

Backend

  • 用 gpt-5-mini 對 row 做 Test Set 分類，分類失敗 fallback 為 Unclassified
  • 產 spec ↔ requirement 對應 preview 供使用者檢查

Step 3 · Generate

User

  • Start Generate / Stop
  • SSE 斷線時從 banner 按 Resume 接續

Backend

  • 建 generate job，透過 SSE 逐筆推送結果
  • Decompose：判斷一筆 requirement 要拆成幾筆 TC；sibling 回 duplicate_of 或 distinguishing_axis
  • 產 TC 欄位（Pre-Cond / Input / Procedure / ER / Method / Priority）
  • 每個成功 batch 立即寫入 usage 紀錄

Step 4 · Review

User

  • Accept / Reject / Edit
  • Regenerate（dialog 填 reason）
  • Re-run（結束顯示 dialog 摘要）

Backend

  • Regenerate：以使用者填入的 reason 為主要修正目標重新生成
  • Re-run：重走 decompose 與 generate 完整 pipeline
  • 有 validation error 時，提供結構化修法建議（root cause / affected fields / proposed change / suggested reason）

Step 5 · Export

User

  • 選 scope（Accepted Only / All Generated）
  • 按 Export 下載 .xlsx

Backend

  • 確認原 Excel 是否仍可掛回，否則改用 blank template
  • 寫回 sheet；缺 Test Set 時補跑 classifier 並記錄 usage
  • TC ID 依 (project, group_abbr) 為 bucket 重新 001/002/003 編號，閉合刪除留下的空隙

4替代路徑：Quick Generate

單筆 requirement 直接出 TC，不開 workbook、不寫回 Excel；結果只進 Job History。

User
貼 requirement
必填：requirement 文字。選填：Additional Context、model。
Backend
Auto-split 串流生成
AI 依 ASPICE SWE.6 §6.1 / §9 / §10.2 自動判斷拆成幾筆 TC，逐張串流回 GUI。
User
Stop
AbortController → Backend disconnect，停送後續 events。
