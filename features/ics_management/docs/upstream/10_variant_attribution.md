## §9 獨立判斷

### 9-1 本包是否仍有該驗而未驗者 —— **有，四項**

1. **§2-4 之衝突未解**（見 §8-1）。這是本包量完之後**新開的最大一個洞** ——
   量得變體不等於量得「§1.18 對本 DUT 之地位」，二者被我們**默認為同一件事，而 SYS2 說不是**。
2. **CFTS022 之變體軸未量**（§3-5-4）。7 條 TC 之安全性建立在一個未量之假設上。
3. **09 §1 之三條覆蓋判可能因 NBSP 缺陷而誤**（§3-5-1）。已作敏感度但未重跑。
4. **V1／V2／V3 之 popup 面連續八包無進展**。線索在不在 repo 之 `HMI Pop Up List`。
   **此判斷已第四次重複，不再重述。**

### 9-2 【下放包 §6 指定】若判 Associated，b03 之 8 條應如何處置（**只建議不裁**）

**本包量得 Disassociated，故本題為假設性；但仍照答，因其答案對 §2-4 之衝突有用。**

**建議一：不是「重錨」，是「退回未生成態」。**
b03 八條中**可救者僅 1 條**（b03-08，`4821705` 對位良好）。
其餘七條之失據**不在 DCSD 前提**（只 5／8 提及），而在
**§1.18 全節無 `$TGW_DISP_STAT$`／`$RQ_DISP_INTS$`、無三秒窗、無「POWER 鍵控 HU 螢幕」母條**。
一個沒有母條的行為面，不該用「改錨」來假裝它還在 —— **應退回未生成態並登為覆蓋缺口**。

**建議二：退回之同時，DR-ICS16 應自「上游急件」升為「阻斷交付」。**
b03 八條是 Display Control 之全部；退回即該 Test Set 歸零，
而 framework 之 Layer 2 會少一組。

**建議三：`4819541` 之六（實為七）個時間定值失源，應與 b03 分開處理。**
它牽連的 6 條分佈在 b01／b02／b04 三批、三個不同 Test Set ——
與 b03 之整組退回不同，那 6 條是**個別條目失去一個欄位之值**，
退回佔位即可，不必退回整條。
