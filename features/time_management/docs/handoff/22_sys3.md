## 3. **A-TM09 之 48 筆缺口 —— 可能已由 SYS3 關閉**

分析層實測 SYS3 全文之 `SYS-RA-TIME&DATE-nnn` 引用：

```
相異 id 數   126
範圍         009 – 229
```

**126 恰等於 SYS2 之 Functional Requirement 總數**（本 feature 先前實測值）。

**若兩者為同一集合**，則：

- SYS3 **完整涵蓋全部 126 筆 FR**，與版本 C 之修訂說明
  「complete source coverage, requirement allocation」相符
- A-TM09 之「48 筆無對應」**不是缺口，是分配結果** ——
  該 48 筆在 SYS.3 層被分配給 HU 軟體以外之單元（IPC / LTM），
  故 037（SWE.1，HU 軟體之需求分析）未涵蓋

**分析層不下此結論**，因：

1. 「126 = 126」為**計數相等**，非集合相等。兩者可能各有出入而數目巧合
2. 比對所用之 SYS2／037 副本已隨 session 失效，無法即時複驗
3. SYS3 是否真為「分配」而非「僅引用」，須讀 §4.3 之實際內容

**T2 指派執行層對 `inputs/` 之檔案做集合比對。**
