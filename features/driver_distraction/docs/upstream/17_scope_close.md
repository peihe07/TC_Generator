## 四、T26c 之目視核對 —— **profile §5 有一字之誤，非異體字，是別字**

**未逕改**（T26c 為分析層自辦）。

| | 字 | 碼位 | 字義 |
|---|---|---|---|
| profile §5 現書 | `速度遲**滾**` | **U+6EFE** | 滾 = 翻滾／沸騰 |
| 應為 | `速度遲**滯**` | **U+6EEF** | 滯 = 停滯；**遲滯 = hysteresis** |

- **位置**：`docs/runtime/profiles/FW036_R1L_DriverDistraction_Profile.md` **第 175 行**，
  §5 表之 **A-DD1／DR-DD1 列**，依據三之第 2 項：
  `SYSAD 載速度遲滾為 JudgmentProcessorType4to6 … for LATAM`
- **命中數**：profile 全檔 `速度遲.` 命中 **1**，即該處；**無其他處**

**校對之依據（三方一致，唯此處不同）**：

| 來源 | 字 | 碼位 |
|---|---|---|
| 下放包 20 §二(b) 第 2 項（**profile 該句之來源**）| 遲**滯** | U+6EEF |
| `docs/handoff/14_framework_fix.md`（4 處）| 遲**滯** | U+6EEF |
| `docs/upstream/11_framework_fix.md`（3 處）| 遲**滯** | U+6EEF |
| **profile §5 第 175 行** | 遲**滾** | **U+6EFE** |

**判為別字而非異體字之理由**：異體字為同一字之不同寫法（如 `滯`／`滞`，U+6EEF／U+6EDE），
二者**同義**；本件之 `滾`（U+6EFE）與 `滯`（U+6EEF）**是兩個不同的字**，
`遲滾` 在中文中不成詞。**碼位相鄰（6EEF／6EFE）**，形態上像輸入法候選字選錯，
非簡繁轉換或異體正規化所致。

> **值得記一句**：這一字之誤**不影響任何機器判準** ——
> 本輪所有自檢、盤點、閉合皆不讀該句。
> 它只影響**人讀該條依據時能否看懂**。
> **沒有任何一個檢會抓到它**，這正是它需要被目視核對的原因。
