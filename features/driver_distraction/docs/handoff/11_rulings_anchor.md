## 一、R-DD14（條文）

```
R-DD14（RULINGS.md 之錨點體例）

`scripts/rulings_hash.py` 之錨點正則要求 `## R-…` 形式之標題，
其「條文本體」定義自錨點標題之次行起、至下一個同級或更高級標題之前一行止。
本 feature 之 `RULINGS.md` 採圍籬體例，**無標題錨點**，
故該工具收錄 0 條（上繳包 07 §1.1 實測）。

裁定（Pei 2026-08-28 准）：

(a) 於每一條文之圍籬**上方**加標題錨點 `## R-DDn`（留存版加
    `## R-DDn v1`，其標題文字須與索引表之留存列一致）。
(b) **加標題為新增行，非對條文本體之刪改** —— 圍籬符號與其內文字
    **一字不動**，故不違 R-TM13。執行層以逐字元 diff 證之：
    改動前後，全檔除新增之標題行與其後必要空行外，**差異須為 0**。
(c) 標題文字**不入雜湊**（工具 docstring 逐字），故加標題不改變
    任何既有條文之 sha 定義域內容；惟本檔原無錨點，
    **本次為自 0 條變為 n 條，非既有 sha 之變動**。
(d) 執行層於改動後以 `--target features/driver_distraction/RULINGS.md`
    導向 scratchpad 試跑，錨點數須等於現行條文數 ＋ 留存數；
    不等即停並回報，**不得調整條文以遷就工具**。
（Pei 2026-08-28 裁定，下放包 11 §一）
```

## 三、tsv 重生之程序（次序有拘束）

`RULINGS.sha.tsv` 為工具一次寫全之產物，**無「局部」可言**；
故其重生不受 A-DD4「禁整檔覆寫」之限（該限針對人手覆寫他線內容），
**但須以下列程序為之**：

| 序 | 動作 | 停止條件 |
|---|---|---|
| 1 | **T-抄先行** —— R-DD11／R-DD12／R-DD13 逐字入 `RULINGS.md`（包 10 §八）| —— |
| 2 | 加標題錨點（§一 (a)(b)），逐字元 diff 驗 | 差異含條文本體 → 停 |
| 3 | 導向 scratchpad 試跑，驗錨點數 = 13 現行 ＋ 1 留存 = **14** | 不等 → 停 |
| 4 | `--check` 跑一次，**先記錄現行差異全貌** | —— |
| 5 | 重生至 scratchpad，與現行 tsv 逐行 diff，**逐行歸因** | **出現無法歸因於「本線新增 14 列」或「popup 線 R-POP18~20」之差異 → 停並回報，不寫入** |
| 6 | 歸因清白後始寫入 `docs/fw036/RULINGS.sha.tsv`，寫入後 `--check` 須 PASS | FAIL → 回報 |

**第 5 步是本節之核心。** 重生會把**所有** feature 之現況一次寫入 ——
若某線正處於 `RULINGS.md` 已改而未定稿之中間態，重生即把該中間態固化為基線。
**逐行歸因是唯一能發現此事的動作**；不做即為以自己之重生覆蓋他線之未完成品。

> popup 線之 `R-POP18~20`（上繳包 07 §1.3 實測，13 行差異）為**已知且合法**之
> 新增 —— 其 `RULINGS.md` 已改而 tsv 未重生。本次重生將一併收錄，
> **此為順帶結果，非本線之決定**；於上繳包明記，並提示 Pei 知會 popup 線。
