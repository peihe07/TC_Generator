## 2. W-9 全屬性比對表（上繳第 2 項）

**參照列 `r561`**（刪除 r562 後之最末既有資料列）。

### 關鍵發現：參照列自身有 8 種相異樣式簽章

r561 的 36 欄**不是同一種樣式**——實測 8 種簽章（置中/靠左、`wrap_text` 有無、
框線有無各不相同）。**若整列套用同一種樣式，36 欄會全部改錯。**
故 W-9 之實作為**逐欄繼承**：`ws.cell(562+i, c)._style = copy(ws.cell(561, c)._style)`。

### 比對屬性清單（依 R-P86 第 1 項，含相符者）

每格比對之屬性：

| 群 | 屬性 |
|---|---|
| font | `name`, `sz`, `b`, `i`, `u`, `strike`, `vertAlign` |
| fill | `patternType`, `fgColor.rgb` |
| border | `left`, `right`, `top`, `bottom`, `diagonal` 之 style |
| alignment | `horizontal`, `vertical`, `wrap_text`, `shrink_to_fit`, `indent`, `textRotation` |
| protection | `locked`, `hidden` |
| 其他 | `number_format`, `quotePrefix` |
| 列層級 | `height`, `hidden`, `outlineLevel`, `customHeight` |
| 表層級 | `auto_filter.ref` |

### 結果

| 項 | 修復前 | 修復後 |
|---|---|---|
| 樣式不符格數（7 列 × 36 欄 = **252 格**） | 多數不符 | **0** |
| `wrap_text`（c9 / c11 / c12） | `None, None, None` | **`True, True, True`**（同參照列） |
| 框線（c11） | `None` | **`thin`**（同參照列） |
| 自動篩選 `ref` | `$B$1:$AJ$562` | **`$B$1:$AJ$568`** |
| 列高 / 隱藏 / outline | 未繼承 | 繼承自 r561 |

**252 格逐屬性比對，不符 0。** 此為交付檔上之獨立複驗結果，非寫回腳本自述。

> **過程缺陷（我方，兩次）**
> 1. `_style_sig()` 回傳 dict 卻被放進 set 求相異數 → `unhashable type`
> 2. **W-9 迴圈內用 `dst` 當儲存格變數，遮蔽了函式參數 `dst`（輸出路徑）** ——
>    `wb.save(dst)` 因此拿到一個 `Cell`，在 zip 寫入階段才爆
>    （`'Cell' object has no attribute 'write'`），離錯誤點很遠。
>
> 兩次都在複本上發生，交付檔未受影響。第 2 項值得記一筆：**遮蔽不會在遮蔽處
> 報錯，會在很後面的地方以看不懂的訊息報錯。**

### 自動篩選之 `$` 保留

首次實作以 `re.sub(r"\$?(\d+)$", ...)` 延伸，結果為 `$AJ568` ——
**把絕對參照的 `$` 吃掉了**。改為 `re.sub(r"(\$?)\d+$", rf"\g<1>{APPEND_END}", ...)`
後為 `$AJ$568`，與原形式一致。
