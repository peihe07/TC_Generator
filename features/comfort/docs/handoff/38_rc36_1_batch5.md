## 1. §11.1 `mirrored` —— 擴大 R-C36，取消節級之免檢

執行層自陳：`mirrored` 十五列之比對粒度為首句與主要規則，非逐句；
若某節其實只涵蓋九成，它應為 `partial` 而現在不是，**而 R-C36 只對
`partial` 要求 TC 層判定**，故 `mirrored` 是本表最弱之格。

**該診斷正確。且此弱點之成因與 R-C37 同源** —— `mirrored` 是一個未經
陰性側檢視之陽性判定，而它現在承載 45 條之排除式 PC。

逐句複核十五節可解，但**解錯了問題**：問題不在該判定粒度不夠，
而在**節級判定被允許代替 TC 級判定**。粒度再細，代替關係仍在。

```
R-C36-1  R-C36 之擴大：TC 層之問句不因節級強度而免除

R-C36 原文限於 `partial`。自本條起，**不論節級鏡射強度為何**，
每條 TC 皆須回答同一問句：

  本條之可觀察行為，是否落在 ch16 對應節所涵蓋之部分？

節級強度（`mirrored`／`partial`／`no-counterpart`）之作用改為兩項：
  一、提供該問句之**預設答案**與**證據出處**
  二、`no-counterpart` 者其答案必為「否」，不需逐條重問

`mirrored` 者之預設答案為「是」，但**預設不等於免答** —— 該條之
`interface_axis_review.emea_ics` 須載其判定，且判定須指向 ch16 對應節
之具體句，非僅引「該節為 mirrored」。

R-C36 原文不改寫，於其後附本條。
```

**回溯範圍**：現有 45 條帶 EMEA 排除式 PC 者，其所屬節於表中為 `mirrored`
或 `partial`。**逐條補答**，答案與依據入
`data/interface_axis_review.tsv` 之 `emea_ics` 欄。

答「否」者 → 該條之排除式 PC 過嚴，回報清單，**不自行移除**
（同 §1 之前例：移除須經裁定）。

**逐句複核十五列不做** —— 其成本高於本條，而本條之覆蓋更完整：
即使某節被誤判為 `mirrored`，TC 層之問句仍會在該條上問一次。

## 3. §6.2 —— `7.4` 之 `500 ms` **不進 `-055` 之 ER**

執行層記「在那之前，該 TC 之 ER 比條文所能支持的更弱」。**該措辭須訂正。**

`500 ms` 是 **7.4（`Rear Climate`）自身之門檻**。`-055` 屬 2.6.x
（`Temperature and Fan`）。依 §8.2.1 與 R-C28 第一問：**除非 2.6.x 之
full_text 自身載有門檻，否則不得寫入** —— 寫入即為以他節之數值補值
（§8.4.1）。

故 `-055` 之 ER **不是「比條文所能支持的更弱」，而是恰好等於 2.6.x 所支持
的強度**。若 2.6.x 確實隱含一個時間條件而未給值，那是**內容缺口**，
登 RD-1 候選，不是 ER 該補的東西。

指示：複查 2.6／2.6.1 之 full_text 是否載有任何時間條件；
- 有具體值 → `-055` 之 ER 依該值改寫
- 有條件而無值 → 登 RD-1 候選，ER 不變
- 無 → 現狀正確，於 `reasoning` 具名 `7.4` 之門檻屬 `Rear Climate`

`7.4` 之 `500 ms` 於 `Rear Climate` 生成時方進其 TC，屆時為該組之事。

## 4. §11.4 —— `sibling_candidates.py` 之組別解析：**須反向驗證**

解析若某節錯組，跨組判定即失效而無人知 —— 其失敗形態為靜默。

反向驗證：注入一個 `framework.md` 之損壞形態（如刪去某組之區間展開、
或把某節移入錯組），確認產生器**報錯或產生可辨之異常輸出**，
而非靜默地少產／多產候選。

另加一項不需注入之檢查：解析所得之
**「節 → 組」映射總數須等於 129，且每節恰屬一組**，
與 `test_set_map.tsv` 逐節比對，不符即 FAIL。
