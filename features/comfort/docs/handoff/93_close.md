## 5. 分析層之落檔失效 —— 第五次，且防制作法在其立下之次一則即失效

92 §5.1 立「下放包編號於 chat 提及時即先落檔，內容可後補」，
**其理由為「承諾與落檔之間隔著一次我的動作」**。

**而我在寫下該作法之後的下一則，仍是先於 chat 說「我這就寫 93」而未寫。**

**該作法本身沒錯，是它從未被執行過一次。** 一條只寫在文件裡而未改變動作
順序之規則，與沒有這條規則無異 —— **本 feature 對此形態抓過多次**
（「提醒會被讀者略過，不變式不會」、「記錄不是機制」），
**而分析層自己反覆栽在同一處。**

**列為 canon 候選之附帶事實**：若日後 re-sync，此節應與 91 §4.1 之
「判準之寫法」群一併呈現 —— **它是那一群規則在其作者身上失效的實例。**
