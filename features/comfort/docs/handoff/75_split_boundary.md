## 1. §1.5 之界線 —— **拆之依據須為條文所列舉之項**

執行層問：「條文列舉之集合不拆／我方選樣之集合應拆」，其界線何在。

**該二者之關係與其所問相反，且答案由 §8.4.1 直接給出。**

```
判準：

**條文列舉了 N 個觸發者 → N 條 TC**（§8.3：sibling 軸各為 1 TC）。
其列舉須可逐字引出。

**條文以泛稱表述而由我方挑選樣本者 → 一條 TC**，所選之樣本為
interaction data，歸 procedure（§4.5）。

理由：**拆分之維度須來自需求，不得來自作者。**
條文寫「A/C、另一氣流模式、或風速皆會破壞 AUTO」，是它給了三個觸發；
條文寫「任一氣候操作會破壞 AUTO」而我方挑了三個來測，
**那三個是我選的，不是它說的** —— 依其拆為三條，即以作者之取樣冒充
需求之維度（§8.4.1）。

**自查**：我能不能把這 N 個項逐字引出來？不能者即為我方選樣。
```

依此逐條複判 §6.1 所列七條（`013-03`／`021-02`／`121-02`／`009-03`／
`023-01`／`023-03`／`036-01`），**回報其條文之列舉句與其判定**。

## 2. 22 條之改判 —— **准，惟每條須引其列舉句**

依 §1 之判準逐條複核後改判。**每一條之 `split_reason` 須引該條文之列舉句**，
不得僅寫「不同 trigger」。

引不出列舉句者**不拆**，並回報其原判定何以成立。

預期淨增約 **+30 列**（22 → 52），惟實數以複核後為準。

**與 74 §2 之關係**：該包否定的是「多個可觀察量＝多條 TC」；
本包確立的是「多個**條文所列**之觸發＝多條 TC」。
**兩者合起來才是完整判準** —— 前者定其不是什麼，後者定其是什麼。

## 3. `110-01` 之漏報 —— 同型須掃

其形態為：procedure 有二次以上「設定為不同值」之步驟，
而其 ER 為**狀態確認**而非後果斷言，故不被新判準視為 trigger。

指示：以該形態為 pattern 掃全 corpus
（procedure 含 ≥2 個 `Set`／`Select`／`Change … to` 且其值相異，
而對應 ER 僅確認該設定已生效者），回報候選數與清單，逐條判。

**「已知漏報 ≥1 而非 =1」之陳述正確**（R-C13）；本項即其處置。

## 4. `105-01`／`105-02`（15.1 之「離開」側）—— **補 TC**

條文 `when a user **enters** (starts a function) **or exits** (breaks a function)
that function` 逐字列舉二者，**依 §1 之判準為條文所列舉之二個觸發**，
而現有二條僅驗「進入」。

**補「離開」側之 TC**，溯同一 leaf，`split_reason` 引該逐字列舉句。

此為本輪唯一**確定須新增而非改判**之缺口。

## 5. §4.3 之 7 節 —— **逐條判其 §7 反向配對**

`2.5.1`／`9.2`／`13.2.1`／`14.3`／`14.13`／`16.4`／`17.2` 經閱讀確認為
真列舉（支援項／有效值）。

逐條判其反向配對是否齊備：**列舉之項是否各有 TC，且是否有至少一條
未支援／無效之反向 TC**（§7）。缺者列為缺口並具名其條文。

**101 個 leaf 未改判為 Q1 候選之處置正確** —— 75% 之誤報率若逕行改判，
會產生一份大而不可信之清單（同 51 §0 之教訓）。

## 6. `127-01`／`-02` 之正規式誤命中 —— 修

`\d+/\d+` 命中螢幕尺寸字串 `8.4/10.1/12`。修正其 pattern 使其不匹配
**引號或吋號相鄰之數字序列**，並回報修正後 Q2 之候選數變化。

**此為判準之瑕疵而非資料之問題**，與 `autojunk`、`${PIPESTATUS[0]}`、
`maxdepth 3` 同族：**工具靜默地量錯了東西，而其輸出看起來正常。**

## 8. 通過、無須處置者

- **判準之關鍵一步**：「動作步驟只有在其 ER 斷言**後果**時才算 trigger」——
  `Turn SYNC on → The SYNC button is highlighted` 為該步自己造成之狀態，
  屬 setup。**該區分使 setup 與 trigger 可機械分辨**
- **按壓循環類 19 條、`024-02`、`024-03`／`-04`、`110-05` 全部落回不適用**
  —— 與 74 §2 之逐項預測一致，且係由新判準自行得出而非照抄
- **逾時不算另一個觸發**（`Wait 3 seconds`）—— 該四條假陽性之理由正確
- **CFTS009／010 命中 44 處而無一涉氣候設定之保持**，且列出其實際內容
  （general reset、restore factory settings、last known radio state）——
  **陰性結論附其命中內容，方能被覆核**
- **`127-01` 之誤命中由讀者發現而非由 gate** —— 其自陳「判準之瑕疵」正確
