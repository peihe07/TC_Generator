**指示**：交付夾另附一份**交付說明**（`README` 或
`Comfort_HMI_delivery_note.md`，檔名由執行層定），內容：

| 涵蓋 | 429 test cases covering **378 of the 403 verification units** in the 037 analysis |
| 未涵蓋 | **26 units**，逐項列 `req_id`｜節｜**一句話說明所缺者**（取自 RD-1 之問句，改寫為陳述句）|

**紀律同 RD-1**（71 §4.2）：無內部語彙（R-Cnn／A-CFnn／gate 名／下放包編號）、
無我方傾向、不預測答案。

## 4. 交付後之狀態

交付**不等於結案**。RD-1 之 26 leaf 仍在，其回覆後之處置：

- 得解者 → 生成其 TC → **再次寫回並交付更新版**（其版本識別以
  `DELIVERY.sha256` 之新 ENTRY 為準）
- 不得解者 → 其缺口狀態轉為長期，於交付說明之下一版註明

**交付說明須載明本次為某一版本而非最終版** —— 一份未標示版本之交付，
其後續更新會被讀成訂正。
