## 1. 預裁其第三項不成立時之處置

**預裁**：若該二節生成後 R-C39 條件三仍不成立，則該 leaf 之內容
**於本 spec 全域未被定義**，屬內容缺口，比照 `2.1` 之 `-01`／`-02`
（DR #17／#20）處置：

- 不產列、不指派 tc_id
- **不入 coverage 分母**
- DR #32 升 **High**，問句改為「`16.16` 所指之 Climate section 為何節？
  該節是否定義 configuration 與 icon 之對照？」
- **不創造第五類 marker**

理由：四類 marker 之共同前提是「我們知道這件事該由誰負責」；
`[COVERED-BY]` 之前提更是內容有主。此處連該由誰負責都未定，
**尚未到分類的階段** —— 再造一個標籤只會把「條文沒說」偽裝成一種已知類別。
