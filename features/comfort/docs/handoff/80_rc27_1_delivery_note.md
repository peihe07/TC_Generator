## 2. 25 vs 26 —— 兩個數皆對，量的不是同一件事

執行層訂正我 79 §2.2 之「26 個 leaf 不產任何列」，實數 **25**：
`SWE1-HVAC-047` 有列（可用側已測），缺者為不可用側。

**惟 RD-1 之摘要表為 26** —— 兩份文件將同時到達不同讀者手上，
**25 與 26 並存而未標示其差別，會被讀成其一有誤。**

```
標示之要求（本包裁定）：

RD-1（致需求方）：`26 units with an open question`
  —— 其量者為「有未答問題之單位」，含部分涵蓋者（`047`）

交付說明（致評閱方）：`25 units with no test case`
  —— 其量者為「工作簿內無任何列之單位」

**交付說明須另以一句說明 `047`**：其可用側已有測試案例，
不可用側因條文未定義而無 —— 使 25 與 26 之差為一個可讀出之事實，
而非一個看似矛盾的數字。

**兩份文件皆須於其數字旁具名其所量者**，不得只寫數字。
```

此即本 pipeline 反覆之教訓：**兩個正確的數字放在一起而未標明其母體，
其效果與一個錯的數字相同。**
