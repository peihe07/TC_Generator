## 2. `hash 與正確性` —— 寫入 `RUNBOOK.md`

> **hash 證明「送出去的和我這裡的是同一份」，不證明「這一份是對的」。**
>
> `<date>` 佔位符從草稿一路留到交付夾，**而它一路上 hash 都相符**。
> 其被發現，是因為交付後仍逐行讀了一次；**若只驗 hash 就收工，
> 它會安靜地待在客戶手上。**

該段與本 pipeline 之既有教訓同族而更根本：

- R-C41（陳述須註明其取得方式）管的是**依據怎麼來的**
- 本則管的是**依據能證明到哪裡** —— 一個完美的 hash 鏈，
  其所保證者僅為「未被竄改」，不涉「內容為真」

**兩者合起來才是完整的**：知道它怎麼來的，且知道它證明得了什麼。

85 §4.3 指示加該 gate（掃 `<…>`／`TBD`／`XXX`／`__` 形態，**判準為形態
