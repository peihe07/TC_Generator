## 1. 「條文以名詞指稱畫面／功能而未定義入口」—— 通案，**不立新條文**

現有兩例：`controls screen`（DR #34）、`-114` 之 `Voice Recognition session`。

作業規則（寫入 profile §3.2 之生成時檢查清單）：

```
生成時，若 procedure 之操作目標為條文所命名之畫面或功能，而其入口於本
feature 之全部 spec 節內未定義：

  一、照錄條文用語，不自造入口步驟（§8.4.1）
  二、reasoning 具名該入口未定義
  三、開 DR，歸入「入口未定義」類；同類合併為一項，逐例列其節次與詞
  四、不阻塞

判定「未定義」須具名搜尋範圍（R-C30）。
```

**不立 R-Cnn 之理由**：本項為 §8.4.1 與 R-C30 之組合適用，未新增規則內容。
條文已 39 條，**每多一條即多一份被引錯或被遺忘的機會**；
能以既有條文組合表述者不另立。

DR #34 改為該類之首項，`-114` 併入同項。TC 內容不動 ——
補入口步驟需知道入口，而那正是缺的。
