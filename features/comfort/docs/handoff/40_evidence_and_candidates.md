## 3. §10.2 候選 205 對 —— **分級判定，不逐對**

`ECO HVAC` 164 對 ＋ `Temperature and Fan` 41 對。逐對人工判定不成比例，
且**其中絕大多數之唯一共有語彙為 `AUTO` 這類泛用控制名**。

```
分級判定之作法（本包授權）：

一、**多重共有者優先**：共有語彙 ≥ 2 之對，逐對判定並記理由。
二、**單一高頻語彙者以類判定**：依其唯一共有語彙分組，每組出一則
    類級判定與理由（例：「`AUTO` 於 N 節出現，係泛用控制名；
    共有該詞不表示述及同一需求」）。
三、**每個類級判定須附抽樣覆核**，且抽樣**須含可能為陰性之候選**
    （R-C37）—— 即刻意挑選「看起來最可能真的是 sibling」的三對，
    逐對讀全文確認，而非挑最明顯不是的三對。
四、類級判定與其抽樣結果入 `pending_sibling.tsv`，
    `verdict` 欄標 `not-sibling (class)` 並記其類與抽樣 tc_id。
```

**類級判定之效力低於逐對判定，須如此標示** —— 日後若某類中發現真 sibling，
該類之判定即失效而非該對之判定失效。

## 4. §10.3 等價組 —— **擴充，且以實測為之**

`3.2` 寫 `turns on Sync` 而 `2.11` 寫 `SYNC`，而 `VOCAB` 之比對為大小寫
敏感 —— **與 `MAX DEFROST` vs `MAX DEF` 同型，且已知它正在漏東西。**

擴充：

1. **比對改為大小寫不敏感**（`SYNC`／`Sync`／`sync` 視為同一）
2. **變體之來源為實測，非憑印象**：掃全 129 節，列出所有以
   `/`、空白、連字號分隔之縮寫形態（`A/C`／`AC`、`MAX A/C`／`MAX AC`、
   `REAR DEF`／`REAR DEFROST` …），據以建立等價組
3. 擴充後**三組與新兩組全部重跑**，`reviewed_at` 更新
4. 依 R-C37，輸出仍須明示其不完備性
