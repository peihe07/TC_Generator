## 1. §4 末 —— `not-sibling` 之回訪：**verdict 加 provisional 旗標**

執行層自陳這是本包最大的未完項，且「不是工作量問題，是機制問題」。
**正確。** 207 對之 `not-sibling` 係以未生成側之**條文**判定，
而其對造將來會有 TC —— 判定之對象與將來被比對之對象不是同一層。

```
機制（本包授權）：

`pending_sibling.tsv` 增 `provisional` 欄（布林）：
  兩側皆已生成 → false
  任一側未生成 → **true，不論 verdict 為 sibling 或 not-sibling**

`pending-sibling` gate 擴充：某 Test Set 全數生成之日，
凡涉及該組節次且 `provisional == true` 之列，一律 FAIL，
訊息列出其對與現行 verdict，要求重新確認後將 `provisional` 置 false。

**重新確認得維持原 verdict** —— 要求的是再看一次，不是要求改判。
```

現行 `duplicate_of` 之暫空機制不變；本欄涵蓋的是**已判但依據不足**者，
兩者互補。

## 2. §3.1 —— 規則三取不到值：**改產生器，`deferred` 入表**

規則三（兩節皆未生成 → 標 `deferred`）現無對象，因產生器只輸出涉及已生成
節之對。**規則存在而無對象，等於規則不存在** —— 那些對現在既未判、
亦不在表中，**不可見**。

指示：產生器改為輸出**全部**符合語彙條件之對，兩節皆未生成者
`verdict = deferred`、`provisional = true`。

**表由機器維護，不得手工增修** —— 其規模將達數千列，手工維護必然失同步。
每次執行為全量重建（非增量），並保留人工判定過之 verdict：
以 `(節A, 節B)` 為鍵合併，鍵不存在者新增為 `deferred`，
鍵已存在且 verdict 非 `deferred` 者保留其判定與理由。

回報重建後之列數與各 verdict 之分布。

## 3. §3.3 第三軸之第三值 —— 先證後改，條件三項

**不以「可能」改軸。** 若三項齊備即自行增值（此為客觀條件，非判斷）：

1. 該第三值在條文中**逐字出現**，具名其節次與句
2. 該值與現有二值**互斥且窮盡**，或條文明示其為第三種並列情形
3. 三值皆非由推論補齊

齊備 → 更新 profile 之該軸值清單與值數。
**`axis-value-count` gate 屆時將 FAIL** —— 那是它的設計目的：
65 條 negation users 必須被重新覆核，
`negation-reviewed-at-value-count` 方得更新為 3。

**該 FAIL 不是缺陷，是本輪最值得看的一次 gate 動作** —— 34 §4 立它時
所設想的情形第一次發生。

三項不齊 → 不改，回報缺哪一項。

## 6. §8 第 4 點 —— R-C36-1 適用於**所有**鏡射表，非僅 ch16

執行層問 `ch2_ch7_mirror_map.tsv` 之 `mirrored` 是否比照 R-C36-1。

**是，且不需新條文。** R-C36-1 之措辭為「不論節級鏡射強度為何」，
其約束對象是**以節級強度支持 TC 級判定**這個動作，不是 ch16 這張表。
**條文之適用範圍由其理由決定，不由其首次適用之對象決定。**

釐清（寫入 `RULINGS.md` R-C36-1 之旁註，不改原文）：

> R-C36-1 適用於任何以節級對應強度支持 TC 級判定之情形，
> 含 `ch2_ch7_mirror_map.tsv` 及日後新建之任何對應表。
> 節級強度提供預設與證據出處；TC 級問句不因之免除。

故 `ch2_ch7` 之三列 `mirrored`，於 `Rear Climate` 生成時逐條問，
不得以節級強度代填。
