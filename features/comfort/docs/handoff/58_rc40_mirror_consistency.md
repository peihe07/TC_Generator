## 1. §6.2／§9.1 —— `2.11` 停而 `16.11` 生成：**立條文並解此案**

兩節句子**逐字相同**，而其一停下、其一生成。執行層判「兩者不該並存」——
**正確，且此形態將隨鏡射表之使用而反覆出現**，故立條文。

```
R-C40  逐字相同之條文，其兩處實例之處置須一致

同一條文於兩節逐字重述者（鏡射對、前後排對、carryover 對），
其 leaf 之可生成性不得因所在章節而異。

不一致時，須先答一問：

  **停下之依據，是條文本身之性質，抑或該節所在章節之脈絡？**

  條文性質（措辭不足、對照未定義、值未列舉）→ 兩側皆停，
    已生成之一側須撤下並登記
  章節脈絡（該章特有之軸未定、該章之對造缺席）→ 依據不轉移，
    不一致為實然，於兩側之 reasoning 各具名其理由

判不出者取**較保守之一側**（停下），不得以「另一側已生成」為生成之依據。
```

**本案之處置**：回報 `015-04`／`015-05` 停下之原始理由，套用上列一問。

- 依據為條文性質 → `-224`／`-225` **撤下**，並記其撤下之依據
- 依據為 ch2 之脈絡 → 兩側各具名理由，`2.11` 維持停下

**不得逕以「16.11 已生成」解封 `2.11`** —— 那是以結果為依據。

## 2. §8.2 兩類交會 —— **記於成因所在之類，另一類加交叉註記**

`16.5`／`2.5` 之 recirc 圖示同屬 DR #32（對照未定義）與 DR #34(h)
（可執行性依賴測試員已知答案）。

**其成因為對照未定義** —— 測試員之所以須自行知道答案，正是因為對照不存在。
(h) 之形態是**後果**，不是另一個成因。

處置：**成員籍屬 #32**；於 #32 之該成員條目加交叉註記，指向 #34(h)
之形態；#34 不重複列該成員。

**通則**（`RUNBOOK.md`，與 36 §2／50 §3／56 §1 並列）：

> 一項落在兩類之交會時，**依其成因歸類，依其後果註記**。
> 兩類皆列，會使兩邊的計數都變得不可信 ——
> 而計數正是上游用來排優先度的東西（56 §1）。

執行層自陳「兩個類項在此交會，而我把它只記進了 #32」——
**該處置即為正解，其自陳之疑慮不成立**，惟缺交叉註記，補之。

## 3. §8.4 `16.13` 六條之重疊 —— **是 §4.6 不是 §4.5**

§4.5 管**一條 TC 之內**資料屬於哪個欄位；六條退出途徑為六條 TC，
其重疊為 sibling 重疊，屬 §4.6。

**此為第二次同型訂正**（前次為 50 §4 之 `17.1` 三條），故一併寫入
`RUNBOOK.md`：

> **§4.5 是欄位歸屬（一條之內），§4.6 是 sibling（跨條）。**
> 跨條之相似不論多高，都不是 §4.5 之問題。

處置：六條各補 `distinguishing_axis`（其退出途徑之具體 token），
並依 §10.6 四項逐條判 `duplicate_of`。**預期不構成**（觸發鍵各異），
但須明寫其判定，不得以「顯然不同」代之。
