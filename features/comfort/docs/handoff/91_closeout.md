## 2. 兩種錯之分別 —— 寫入 `RUNBOOK.md`，並列為 canon 候選

> **「沒查而說沒有」（Q7）與「查了但把結果說得比它大」（Q6）**
> —— 後者較難發現，因為**它的每一步都做了，只有最後一句話跨出了範圍**。

本 feature 對前者已有機制（R-C13 換路徑、R-C30 載明搜尋範圍）；
**對後者沒有**。其失效形態是：過程無瑕，而結論之範圍大於過程之範圍。

連帶之措辭分別一併記：

> **`we have` → `we have read`** ——「我們有的」與「我們讀過的」不是同一個集合，
> 而可稽核的是後者。

**兩者皆為 canon 候選**（§4）。
