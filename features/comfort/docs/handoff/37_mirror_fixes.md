## 2. §5.3／§6.4 —— `partial` 之處置：**下放至 TC 層**

`mirrored` → 排除成立；`no-counterpart` → 排除過嚴。`partial` 落在中間，
而**節級的 `partial` 不足以決定 TC 級的排除**。

```
R-C36  鏡射強度為 partial 者，排除之判定下放至 TC 層

某節於 ch16 之對應強度為 `partial`（ch16 涵蓋其部分行為）時，
不得以節級強度決定該節全部 TC 之排除式 PC。逐條問：

  本條之可觀察行為，是否落在 ch16 對應節所涵蓋之那一部分？

  是   → EMEA ICS 車輛以 ch16 之介面實現該行為 → 排除式 PC 成立
  否   → 該行為於 ch16 無對應 → 排除式 PC 過嚴，不寫入，並具名理由
  判不出 → 停下回報，不以節級強度代填

依據：R-C35。節級 `partial` 是關於**該節**之一般命題，
而所判者為**該條 TC 之可觀察行為**；前件與所判之事不同一。

`ch16_mirror_map.tsv` 之 `partial` 列須另增一欄，記其**涵蓋與未涵蓋之
行為分界**，使 TC 層之判定有可引之依據，而非每次重讀。
```

現時影響 `3.3` 之 2 條；`Climate Modes` 與 `Airflow and Defrost` 生成時
將涉 2.4／2.5／2.8／2.9／2.13 五節。**該分界欄須於那兩組生成前備妥。**

## 3. §5.3 之方法論發現 —— 立條文

執行層自陳：

> 三個樣本（2.2、2.14、3.1 之 MODE 循環）全部選自有對應者……
> **歸納之樣本若全部取自陽性側，其結論必然是「普遍成立」。**
> 這與 §4.1 判別是同一形態：我用一組正例得出一條規則，然後把它當成判準用。

**同一失效形態在本 feature 已第二次造成實質後果**（§4.1 之選擇子判別、
本次之鏡射歸納），故立條文而非僅記 RUNBOOK。

```
R-C37  以樣本支持全稱結論者，樣本須含陰性側

凡結論之形式為「X 普遍成立」而依據為若干樣本者，樣本之選取須包含
**可能為陰性之候選**，並記其實測結果。

樣本全部取自陽性側時，該結論之真值與樣本無關 —— 它必然為「成立」。
此時之陳述僅得為「已檢視之 N 例皆成立」，不得為「普遍成立」。

自查：問「我是怎麼選到這幾個樣本的？」若答案是「它們是我先想到的」
或「它們是明顯的例子」，則陰性側未被檢視。

前例：§4.1 之選擇子判別（四個正例 → 誤為判準）；ch16 鏡射之三樣本歸納
（三例皆有對應 → 誤為全章鏡射，實際 7 節無對應）。
```

## 4. §2.1 —— `2.7.1` 之條件 1：**依子條讀法成立**，增第十四軸

`C6.1` 為 `C6.` 之子條。合讀非推論，而是同一需求之兩條文字；
跨節取據本即 R-C29 所允許，且**執行層自行併陳可能推翻自身結論之讀法**，
處置正確。

更關鍵者：`2.7.1` 之首語為 **`In some vehicles`** —— 該句自身即宣告一個
配置變數。條件 1 之用意是防止**由推論補齊未列之值**，而此處兩值皆為逐字。

```
第十四軸  前排 HVAC 風速範圍
  值：Off, 1-7（來源節 2.7，`C6.`）／ Off, 1-8（來源節 2.7.1，`C6.1`）
  類別：功能型（兩值皆不移除任何介面，改變者為值域）
  既有影響：0 條（執行層實測，2.7 之 5 條無一依賴上界）
```

`2.7.1` 之 1 leaf 可生成。其 PC 須標 `(2.7.1)` 為 `1-8` 之出處；
若引 `1-7` 作對照，標 `(2.7)` 並併入 `specification_reference`（R-C29）。

## 6. §6.6 —— `PENDING_SIBLING` 之完整性

執行層：「沒有任何檢查會問『還有哪些 sibling 該入表』」。**正確。**

無法機械判定「兩節是否為 sibling」，但可機械產生候選，並使該產生成為
**每組完成時之必經步驟**：

- 候選產生器：跨 Test Set 之節對，其 `full_text` 共有**至少一個**
  條文自有之大寫語彙（`SYNC`、`MAX DEF`、`RECIRC`、`AUTO` 等）
- **每個 Test Set 全數生成之日**，對該組之節與**全部其他節**跑一次，
  輸出候選清單；逐項判定為 sibling 或否，**判定結果與理由入表**
- 表內另記 `reviewed_at`：該組完成時之全 feature 節數，
  使「表在哪一輪被覆核過」可查

**依 R-C37，此候選產生器不得作為完整性之證明** —— 其輸出須明示
「本清單由語彙重疊產生，未涵蓋無共同語彙之 sibling」。
