## 1. `044-02` —— 兩個選項都不對，立第三類

### 1.1 R-C16 不適用（推翻執行層之建議，亦推翻我 40 §1 之預設）

**R-C16 之覆蓋缺口指「該節屬交付範圍，而 037 未對其產出需求」。**
`044-02` 之情形相反：**037 產出了需求**，有 leaf、有 id、在 403 之內。

以 R-C16 處置會使一個 037 明確產出之 leaf 在工作簿中**不留任何痕跡** ——
評閱方比對 037 與工作簿時，該 leaf 憑空消失。那正是 BLOCKED row 機制當初
存在的理由（Privacy：「使 traceability 表帶著一個可見、可稽核的缺口，
而不是一個無聲的」）。

執行層之三欄對照表已證其非 `[BLOCKED-SPEC]`；其自行提出之 R-C16 亦不合，
但**它把「現況已與之相同」寫出來，使我看得見那個現況正是問題所在**。

### 1.2 立條文

```
R-C38  非 HMI 可觀察性質之 leaf —— [BLOCKED-NON-HMI]

某 leaf 之內容既未委派予外部文件，亦非任何介面可觀察之行為，
於本 feature 全部 spec 內無可觀察端者：**產出 BLOCKED row**，
marker 為 `[BLOCKED-NON-HMI]`。

與既有兩類之別：
  [BLOCKED-ECU]      行為由另一 ECU 執行，本 ECU 無可觀察端
  [BLOCKED-SPEC]     行為可觀察，但其規範內容由另一份 spec 擁有
  [BLOCKED-NON-HMI]  無外部擁有者，且其內容不是介面行為

使用條件（五項全備方得使用，缺一即回報停下）：
  一、條文內無任何委派字面（`see`／`as per`／`refer to`／具名文件）
  二、037 確實產出該 leaf（非 R-C16 之未分析情形）
  三、於本 feature 全部 spec 節內無可觀察端 —— 須具名已查之節與搜尋範圍
  四、其可能之替代觀察量若已由其他 leaf 涵蓋，須具名該 leaf
      （§4.5：同一可觀察量不得由兩個 leaf 共用）
  五、tc_id 經白名單增列（R-C26）

Remarks 依 R-C27 之可見性排序，首 60 字元內須含
`[BLOCKED-NON-HMI] Not an HMI-observable property` 之意；
**不得填擁有者** —— 沒有擁有者正是本類之定義。

**須同時列 RD-1**：037 對該 leaf 標 `Manual UI Testing` 而其
Expected Result 無任何 UI 可觀察量，係上游之分類問題。
```

`044-02` 五項條件已由補證滿足（一～四）；**白名單增列（第五項）於本包
一併裁定：准。**

RD-1 候選（新增）：`SWE1-HVAC-044-02` 之 Verification Method 標
`Manual UI Testing`，而其 Expected Result 為系統耗電量，無 UI 可觀察端。

## 3. 候選判定之範圍收斂 —— 兩節皆未生成者，延至生成時判

686 對且隨每組完成而增長。**其中多數現在判不出價值** ——
sibling 判定之用途是寫 TC 時決定 `duplicate_of`／`distinguishing_axis`
（§4.6），而兩節皆未生成之對，現在判了也無處可用，且屆時條文理解已不同。

```
判定時點之規則（本包授權）：

一、**兩節皆已生成** → 現在判，逐對。
二、**一節已生成、一節未生成** → 現在判，逐對；
    其結果寫入 `pending_sibling.tsv`，由 `pending-sibling` gate
    於對造節生成時要求回填。
三、**兩節皆未生成** → 標 `deferred`，記其對與共有語彙，不判。
    該組生成之日連同其他候選一併判定（併入既有之「每組完成時跑一次」流程）。

`deferred` 不是 `not-sibling` —— 其 verdict 欄須為 `deferred`，
不得留空或以 `not-sibling` 代填。
```

依此，`class-invalidated` 之 231 對中**僅涉已生成節者須立即逐對判**；
其餘轉 `deferred`。回報三類各若干對。

## 4. §8.2 抽樣力度 —— 類級判定之效力，同 R-C36-1 之形態

**「三對之抽樣力度足以破類，但不足以證類」為正確陳述**，且該不對稱是
本質的：一個反例即證偽，而 N 個正例不證真（R-C37）。

故：

- 通過之四類，其 verdict 措辭一律改為
  **`not-broken-by-3-samples (class)`**，不得為 `not-sibling (class)`
- 該類之成員於**其所屬節生成之日**，依 §3 之規則轉為逐對判定 ——
  類級判定不因曾通過而免除

此與 **R-C36-1** 同形：節級／類級提供預設與證據，TC 級／對級之問句不免除。
