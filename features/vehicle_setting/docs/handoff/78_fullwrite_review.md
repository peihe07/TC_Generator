## 2. R-VS73 —— 判準之調整使數上升者，須逐條抽驗其增量

拆分判準三版：**90 → 71 → 14 → 10**。
前二版若逕採，**會產出 76 條不必要之 TC**。

**R-VS29 已規範「使數下降者須逐筆判定差集」，而上升之方向從未規範。**
本輪之禁區句（「不得為使拆分數上升而拆」）是臨時寫入 50 輪指令的，不是條文。

```
R-VS73（分析層裁定 2026-08-23）
判準之調整**使命中數上升**者，須逐條抽驗其增量：

(1) 自增量（新判準命中而舊判準未命中者）中抽樣，**抽法與抽樣數具名**
(2) 逐條判其為**真陽性**（舊判準過窄）或**偽陽性**（新判準過寬）
(3) 增量非空而未抽驗者，該次調整**不得作為產出之依據**

**與 R-VS29 對稱**：下降須逐筆判定差集，上升須逐條抽驗增量。
**二者之共同理由**：判準之數與判準之對不相干，
而分辨其別只能逐條，不能統計。

實例：W-145 之 v1（90）與 v2（71），其樣本一讀即見非兩個驗證點；
v3 之 14 與 v3′ 之 10 皆經抽驗。**該抽驗擋下 76 條不必要之 TC。**
```
