## 2. 分析層之補測：§九-2 之 425 種未人讀，以關聯度量收窄

上繳 §九-2 具名：排除清單為二形態，**而全庫上半 distinct 427 種，
其餘 425 種是否另有伴隨句形態未經人讀**。

**本層以「上半 ↔ 下半之關鍵詞重疊」為代理量測全量 438 列**
（去停用詞後之詞集交集；伴隨句之特徵即為與下半之測試目的無共同指涉）：

```
重疊率中位              0.44
重疊詞數 = 0 者            7
重疊詞數 ≤ 1 者           22
```

**7 個零重疊者逐條人讀，皆非伴隨句** —— 其零重疊之因為
**上半以訊號名指涉、下半以設定名指涉**：

```
B376  上 …receives the value via signal $IPC_VEHICLE_SETUP.Tilt_Mirr_Rev$…
      下 …the Tilt Mirror in Reverse setting is displayed as Off…
```

`Tilt_Mirr_Rev` 與 `Tilt Mirror in Reverse` **語意相同而詞形不同**，
故為**本層度量之已知限制，非缺陷**。

**結論**：425 種中未再發現伴隨句形態。**該項自「未人讀」降為「已以代理量測掃過，
零重疊者 7 條皆已人讀且皆非缺陷」。**

**其限制須同時具名**（R-VF95 二）：本度量對「詞形不同而語意相同」不敏感，
**故其為下界而非定數**；若日後發現新形態，補入 `EXCLUDE_UPPER` 並具名輪次。

   setting information is displayed .`），**執行層具名不符並以實測為準**，

   全庫含 `maintain/update` 之句僅 1 種，即 (b) 所欲排除者

   一個「不存在」之回報，其價值等同一個通過之錨點。

