## 1. §7 之配對粒度 —— 讀法 B

```
R-VS74（Pei 2026-08-23）
canon §7 之「enumerated supported items → 須配至少一條 unsupported 負向 TC」，
其配對粒度為 **逐列舉型訊號**（讀法 B），非逐 leaf。

  一個列舉型訊號配至少一條負向 TC 即足；
  同一訊號於多個 leaf 被列舉者，**不逐 leaf 重配**。

現有五條負向 TC 已覆蓋五個列舉型訊號
（`FL_HS_STATSts`／`FR_HS_STATSts`／`FL_VS_STATSts`／`FR_VS_STATSts`／
`Tri_Level_HSW_StatSts`），故**應補 0**。

理由：「無效值被忽略」為訊號處理器之性質，非各需求各自之性質；
同一訊號測二十次同一件事不增加驗證資訊。

**`split_audit.tsv` 之第三類依本條定案**，兩讀並列取消。
**最終 TC 總量之預估依讀法 B 計**（W-147 仍列 A／B 兩數供對照，
惟以 B 為交付之基準）。

**A-VS156 關閉** —— 出處不明之「Pei 裁定 2026-08-23」由本條追認其結論；
惟 R-VS35 之延伸（跨層引用之裁定須具名出處）維持有效。
```

**分析層之但書未採**（同一訊號於不同配置下另配一條）——
Pei 裁定為單純之讀法 B，不加配置維度。**其記於此，不再提。**
