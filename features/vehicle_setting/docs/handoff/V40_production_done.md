## 3. R-VF104 之射程 —— 採甲／乙二分，限於甲型

```
R-VF-甲（R-VF104 射程之界定，分析層裁定 2026-08-24）
【落檔取實測最大 +1，回報實得之號】

**採執行層 §五所提之二分，R-VF104 之射程限於甲型。**

  **甲型（靜默失效）** —— 其被佔用後，錨點之失效**不會被任何機制回報**。
      現知全集：`R-VF99`（`grade_overrides.py:check_rvf48()` 之必命中錨點）。
      **須登錄於 `CROSSLINE.md` 為永久保留位。**

  **乙型（可見失效）** —— 破壞式所用之假值
      （`= 9 (Bogus)`／`SWE1-VC-MutantFamily-001`／`P9`／`W9`／
      `99_vf230_test.md` 等）。其若成真亦使破壞式失效，
      **惟其失效會被「無法失效之項」清單回報。**
      **不須登錄** —— 由可失效測試自行守住。

**二者之別為「失效是否會被回報」，非「是否可能被佔用」。**
**登錄之成本應付予不會自我揭露者。**

**判定之義務**：新增錨點時，作者須自問
「此引用若成真，其失效會被回報嗎？」——**答否者即甲型，須登錄。**
```

## 4. 去重之「保留首條」—— 暫維持，繫於 DR-44

```
R-VF-乙（35 組去重之保留選擇，分析層裁定 2026-08-24）
【落檔取實測最大 +2，回報實得之號】

上繳 §七-2 具名：去重之「保留首條」以**選池序**為據，非以品質為據；
未評估「二者之 `test_item` 何者較適於交付」。**該自我判斷正確。**

**處置：暫維持選池序之選擇，不重選。**

  **理由**：以「條文之完整性」重選，其判準須先確立
  （何謂較完整？節錄較長？觸發與結果俱全？），
  **而該判準之確立所需之工，與 DR-44 覆文可能帶來之結論（二需求應合併為一）
  相比不成比例。**

**DR-44 覆文後之處置分二**：
  上游確認二者為同一需求 → **屆時以條文完整性重選**，其判準隨之確立
  上游確認二者為不同需求 → **35 條去重須全數回復**，
    且其「四欄逐字相同」成為 TC 書寫之缺陷而非上游之重複

**在覆文前，35 組之去重不得被視為已定案** ——
其於交付物中須可還原（保留被去重者之 leaf 清單）。
**已具名於 DR-44，本條令其可還原性須以清單形式落檔。**
```
