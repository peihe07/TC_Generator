## 3. 甲 —— 自驗之射程須與其宣稱相符

```
R-VF-甲（自驗射程之宣稱，分析層裁定 2026-08-25，採納上繳 §二第 4 次）
【落檔取實測最大 +1】

**凡以「全等」「相符」「零差異」為結論之自驗，其比對之射程須涵蓋
該宣稱所及之全部欄位；只比鍵集、只比筆數、只比聚合數者，
**其宣稱須逐字降級為所實比者**（「鍵集全等」「筆數相符」），
**不得以「全等」概括之。**

**成因**：`lid_pairs.tsv` 之自驗第四次前只比鍵集而宣稱「全等」，
**而 1250 筆 `fmt` 欄之差在其射程外**。

**其危險在於「全等」是一個會被信任的詞** —— 讀者不會再問它比了什麼。
**一個射程不足之「全等」，其誤導性高於一個誠實之「未比」。**

**同型先例**：本層 V45 §三稱 x14 替代路徑「已驗其形」，
**而其時只驗元素數與 openpyxl 可讀，未驗 XML 合法性**（V61 §二已更正）。
**二者皆為「宣稱之範圍大於所驗之範圍」。**

**本條亦拘束分析層之抽樣報告**：凡本層以「n 項全綠」報者，
**須列出該 n 項之逐項名稱**，不得只報其數。
```

## 4. 乙 —— §五-4 之推定已有間接證據，其殘餘風險有界

```
R-VF-乙（跨版本解析之推定，分析層裁定 2026-08-25）
【落檔取實測最大 +2】

上繳 §五-4 具名：「本驅動之自驗只驗『重建 v1_76 = 現行檔』，
未驗『其對 v1_78 之解析亦正確』——後者無對照物可比，
其正確性繫於『同一驅動對二本行為一致』之推定，該推定未經獨立驗證。」

**該自我具名正確，而其推定已有間接證據，本條使其成為有界之殘餘而非未知**：

  §三之實測：v1_76 與 v1_78 之**共同鍵 2706 個，其 `fmt` 欄逐欄相異 0**。
  **即同一驅動施於二本，於全部共同鍵上產出相同之值** ——
  **此為該推定之間接證據，非其證明。**

**故殘餘風險限於 v1_78 獨有之 2 個新鍵**
（`CallAction ／ TELEMATIC_VEHICLE_SETUP.CallAction`、
`VC_HdRstPrsnt ／ Headrest_Dump_Present`），**其解析無對照物。**

**處置**：**該 2 鍵逐字人讀其 xlsx 原儲存格與其解析結果**，比對其是否相符。
**2 筆之人讀成本近於零，而其使「無對照物」自 2706 降為 0。**

**通則**：**「無對照物」之範圍應先量測再宣告** ——
其常遠小於初看之範圍。
```
