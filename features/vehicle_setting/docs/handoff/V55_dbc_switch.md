## 1. 甲 —— R-VF120 撤銷；DBC 改用 `forms/` 之二本

```
R-VF-甲（DBC 之取本，Pei 裁定 2026-08-25）
【落檔取實測最大 +1】

**`R-VF120`（判 `forms/` 之 DBC 為「另一車型變體，不取代現行本」）撤銷。**

**改用 `forms/` 之二本**：
```
  forms/PDT27_E2A_R1_BHCAN2.dbc      取代  inputs/PDT27_E2A_R4_BHCAN.dbc
  forms/PDT27_E2A_R1_FDCAN8.dbc      取代  inputs/PDT27_E2A_R5_FDCAN8.dbc
```
**依 R-VF125，改引 `forms/`，不複製入 `inputs/`。**
`inputs/` 之舊二本**標記退役，不刪**（R-VF18）。

**撤銷之理由 —— 本層之推論錯在何處**：

`R-VF120` 之三項依據中，**第二項（`BHCAN2` 與 `BHCAN` 為不同之匯流排名）
之事實成立，而本層據以推出之結論相反** ——
本層由「匯流排名不同」推出「非版次演進，故為變體」，
**而其真實含意為「匯流排本身已更替」**，即**新本才是現行**。

第一、三項亦隨之失其力：
  版號 `R5 → R1` 之「相反」，係因**新基線之版次重新起算**，非回退；
  122 個高壓電池族訊號之消失，係 `BHCAN → BHCAN2` 之**匯流排改組**所致
  （實測 `BHCAN` 883 訊號 → `BHCAN2` 342 訊號，**減 573 增 32**），
  **非車型之變體。**

**本層之錯在於：以「檔名形態」推斷版本關係，而未問使用者實際掛在哪一條匯流排上。**
**該問題本應為 DR-46 之首問，而本層將其寫成了一項推定。**

**二本一併換，不得只換 BH 側**：
  舊組合為 `BHCAN R4 ＋ FDCAN8 R5`（二側版次不同，屬舊基線）；
  新組合為 `BHCAN2 R1 ＋ FDCAN8 R1`（二側同版次，屬新基線）。
  **跨基線混用二本，其一致性無任何來源可保證。**

**DR-46 之範圍收窄**：其「VF230 之目標車型／DBC 取本」一問由本裁定回答；
**僅餘「`90ec` 之標籤錯字」（DR-47 乙）與 LID／DBC 之 EngineRPM 方向差異一項**，
後者依 R-VF123 已判其力較弱。**DR-46 得改為確認型或結案，執行層判之。**
```

## 4. 給 Pei

**我判錯了，已撤銷。**

`R-VF120` 我由「`BHCAN2` 與 `BHCAN` 是不同的匯流排名」推出「所以是另一車型的變體」。
**事實成立而結論相反** —— 匯流排名不同的真實含意是**匯流排本身已經更替**，
新本才是現行。

**本該問的問題我寫成了推定** —— 「你們實際掛在哪一條匯流排上」應該是 DR-46 的首問。

**二本一併換，不只換 BH 側**：舊組合是 `BHCAN R4 ＋ FDCAN8 R5`（二側版次不同），
新組合是 `BHCAN2 R1 ＋ FDCAN8 R1`（二側同版次）。**跨基線混用，其一致性沒有來源可保證。**

**對現行 438 列零影響**（158 個訊號 token，新舊組合各命中 157，
差集雙向皆 0，值域相異 0），**故摘句補正不受影響，續行。**
