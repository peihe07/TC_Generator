## 2. 本線建議（不逆轉 R-VS60）

**不建議**重議 R-VS60。分立 feature 雖可解此問題，但 Part 1 已有
交付內容與已鎖 framework，此時分家之代價高於命名空間之分離。

**建議**：VF230 線改用**獨立前綴**，五個命名空間逐一分離。

| 命名空間 | Part 1 線（不動） | VF230 線（改） |
|---|---|---|
| handoff／upstream | `NN_` 兩位數字 | `VNN_`（`V01_`、`V02_`…） |
| 裁決 | `R-VS{n}` | `R-VF{n}` |
| anomaly | `A-VS{n}` | `A-VF{n}` |
| 工單 | `W-{n}` | `W-VF{n}` |
| **DR** | `DR-{n}` | **不分離，續用同一序** |

**DR 刻意不分離之理由**：DR 為對外提問，覆文以號對應。同一上游收到
`DR-12` 與 `DR-VF12` 兩件會使覆文歸屬不明；其代價高於內部命名空間之整齊。
DR 之開號改為**開號前查 `DATA_REQUESTS.md` 之最大已用號，且於同一檔內開立**，
以檔案本身為唯一之序。
