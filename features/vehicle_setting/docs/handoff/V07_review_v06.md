## 3. R-VF18 —— 歷史數不追改；只改現行有效之陳述

```
R-VF18（既有數字陳述之更新界線，分析層裁定 2026-08-23，
採納上繳 V06 §5 之判斷）

母體、分母或判準變更時（如 619 → 627），**既有文件中之舊數不一律改**。

  **不改**：作成當時為正確量測之歷史紀錄 —— 上繳包、已結案之報告、
           條文中引為理由之當時實測值。改之會使歷史失真，
           且使「當時據何而裁」不可考。
  **須改**：**現行有效之陳述** —— 後續作業會據以行動者，
           例如 `feature.yaml`、現行腳本之常數、PLAYBOOK §6 狀態板、
           仍在生效之判準文字。

**判斷須逐句為之，不得以檔為單位整批處理。** 同一檔內可能兼有兩類。

**改與不改皆須留痕**：不改者於該處或於上繳具名「此為當時量測，
依 R-VF18 保留」；改者具名新舊值與其依據。

理由：上繳 V06 §5 掃出 18 檔含 `619`，其中多數為當時之正確量測。
一律追改與一律不追改皆錯 —— 前者失真，後者使現行作業依舊數而行。
```
