## 2. 甲 —— 佔位式不適用 R-VF119；維持 444

```
R-VF-甲（R-VF101 與 R-VF119 之交互作用，分析層裁定 2026-08-25）
【落檔取實測最大 +1】

**佔位式（R-VF101）之 85 條不適用 R-VF119 之拆。維持 444 列，不增至 641。**

**二者所處理之情形在種類上不同**：

  **條文明列多值**（`seq 414` 之 `0sec/30sec/60sec/90sec`）
    → 各值為**條文所定之規格分區**，其結果由條文分別指定，各自可獨立失效
    → **必拆**（canon §8.3 等價分割；§7 列舉須配對）

  **條文未指定值，值域取自 DBC**（85 條佔位式）
    → **條文未言各值有相異之結果**。依 DBC 值域拆為 N 條，
      係本層自行主張「每值皆應被驗」，**而條文未如此要求**。

**決定性之理由不在原則而在其產物**：條文既未區分各值之結果，
則該 N 條之 `expected_result` **必然逐字相同** ——
其即 `R-VF105`／`R-VF106` 所攔之「可執行四欄逐字相同」，
**197 列之新增將是 197 組實質重複。**

**且其違反 canon §8.4.2**：以 DBC（實作之快照）之值域決定驗證之範圍，
即以快照擴張規格所未擁有者。

**解除條件**：`DR-39`（條文未指名值時該送何值）之覆文若指明各值之結果相異，
**屆時該 85 條依 R-VF119 重拆**，其增量以覆文所涵蓋者為限。
```

## 3. 乙 —— `seq 414` 四列不構成實質重複；試作核可

```
R-VF-乙（多值拆列之重複判準，分析層裁定 2026-08-25）
【落檔取實測最大 +2】

上繳 §七-3 具名待判：`seq 414` 之四列其上半逐字相同、下半僅值相異，
是否構成 canon §4.3.1 所欲避免之實質重複？

**判：不構成。**

**判準為既有之 `R-VF105`／`R-VF106`（可執行四欄逐字相同），非「上半是否相同」。**
四列之 `test_procedure` 與 `expected_result` 皆隨其值而異
（`displayed as 30sec` vs `0sec` …），**四欄不逐字相同，故不命中。**

**且「上半相同、下半各異」正為 PM 之常態** —— 實測 PM 之上半 175 種
衍生 390 列，**其最大者一上半衍生 12 列**。
canon §4.3.1 所禁者為「**括號下半**逐字相同」，非上半相同。

**試作 8 列核可**：格式合 R-VF118，四項自檢皆實測可失效，
下半之二端逐字取自 `test_procedure` 末步與 `expected_result` 末項。
**得據以全量施行。**
```
