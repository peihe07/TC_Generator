## 1. 獨立複驗（canon §5a 條 16）

分析層自 `inputs/` 原始 xlsx 讀取，**不做任何正規化**：

```
r695 ESS_ENG_ST
  AtlHigh Signal : 'STATUS_CCAN3.ESS_ENG_ST\nENGINE_FD_2.ESS_ENG_ST'
  AtlHigh CAN    : 'CAN-B\nFD'
r938 HSW_Stat
  AtlHigh Signal : 'STATUS_CSWM.HSW_STATSts\nSTATUS_CSWM.HSW_STATFailSts'
  AtlHigh CAN    : 'CAN-B'
```

三項確認：

1. **分隔符確為換行**（`\n`），非空白 —— 故「壓平換行」確實摧毀語義，
   A-VS29 之成因診斷正確。
2. **A-VS26 之降級依據成立**：單格兩 message、CAN 欄兩網段同序對齊。
3. **`HSW_Stat` 之 CAN 欄只有一行而 signal 欄有兩行** —— 執行層
   「`can` 行數不足者留空，不猜、不循環補」之處置正確。
   若循環補，第二支會被標成 `CAN-B` 而看似有據，實則是編造（§8.4.1）。

## 2. C3 第四次現身 —— 下移之軌跡須立為條文

四次之位置逐次下移：

| 次 | 輪 | 位置 |
|---|---|---|
| 1 | W-8 | 值域**切分式**（以逗號切，該欄無逗號） |
| 2 | W-15b′ | **配對式**（交叉配 vs 逐對配） |
| 3 | A-VS26 | **單格多值**未展開（只取第一個 message） |
| 4 | 本輪 | **中介檔之寫出端**（`" ".join(split())` 壓平換行） |

前三次皆在「讀取與比對」，第四次在「**寫出**」——
**修了讀取端，卻在寫出端把來源的語義分隔符丟掉，下一次讀取因而再度有損。**

```
R-VS26（衍生檔紀律，待 Pei 裁）
(1) 衍生檔（`data/*.tsv` 等）之寫出，**不得改變來源之語義分隔符**。
    來源以換行區分多個條目者，衍生檔須保留該區分
    （逐條目一列，或以不出現於資料中之逸出序列表示），
    不得以 `" ".join(cell.split())` 之類壓平。

(2) **凡需要語義結構之比對，一律自來源重建，不以衍生檔為輸入。**
    衍生檔之定位為「供人讀之快照」與「跨輪次之對照基準」，
    不是比對之輸入。

(3) 一份衍生檔若經證實有損，須於檔頭首行加註
        # SUPERSEDED — lossy, do not use as input; rebuilt by <script>
    並於同輪次之上繳包具名列出其下游使用者。
    **實際刪除屬 Pei**（版控範圍），分析層與執行層皆只標記。

理由：C3 之四次現身中，第 1–3 次修的是讀取，第 4 次證明
**寫出端與讀取端是同一條鏈**；只修一端，缺陷會在另一端重現。
```

**現行標的**：`data/lid_map.tsv`（W-14 之產物，已知有損）
與 `data/lid_pairs.tsv`（本輪產物，`fmt` 欄有損）。
兩者皆須依 (3) 加註，並列出下游使用者。

## 5. 待判 16 項之處置 —— 本輪不裁，但先分類

上繳 §2.2 已逐項描述。分析層閱後之分類（**供 07 輪使用，非裁決**）：

| 群 | token | 性質 |
|---|---|---|
| **已登記** | `$VC_VEH_LINE$`／`$TGW_DISP_STAT$`／`$PowerMode$` | DR-8／A-VS23／DR-12，已有處置 |
| **可能為真問題** | `$FL_VS_RQ_TGW$`／`$FR_VS_RQ_TGW$`／`$FR_HS_RQ$` | CFTS 對**請求訊號**列三階，DBC／LID 僅 pressed／not pressed。**若請求訊號真的只有二值，則 CFTS 之三階描述指的是別的東西** —— 這會直接影響 procedure 之操作步驟怎麼寫 |
| **可能為真問題** | `$EngRun_Stat$` | 兩套命名體系無交集之語義對應 |
| **判準不足** | `$Hybrid_Type$`（複合值破壞 C5）／`$HSW_Stat$`／`$HSW_Stat_2$`（C1/C2 混合） | 修判準即收斂 |

**第二、三群（四個 token）為 07 輪之待判重點**；
其中請求訊號之三階／二值問題**最可能改變 TC 內容**，
建議 07 輪為其開一個具名作業，不與判準修正混在一起。
