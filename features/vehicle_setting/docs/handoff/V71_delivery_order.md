## 2. 成因：`R-VS58` 之選池序被直接當成交付序

`R-VS58` 令選池序為「**P0→P1→P2；同序內逐 Layer 2 輪流 ＋ reqid 升冪**」。

**其目的為批次之組成** —— 使每一批涵蓋多個 Test Set 與多種形態，
**以免一整批同質而 pilot 之覆蓋面不足**（`R-VF61` 之分層取樣同源）。

**而本層自始未區分「生成序」與「交付序」，遂使選池序直接成為工作簿之列序。**
**該決定從未被任何一條裁定明示，其為預設之延續。**

**二者之目的相反**：
- **生成序**求**異質**（每批涵蓋面廣）
- **交付序**求**同質**（同一需求之各列相鄰，使人可讀、可核）
