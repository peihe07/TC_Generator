## 1. 兩個數字擇一 —— 取 **(b) = 1**

執行層並列 (b)=0（其判準）與 (b)=1（納入裸值），不擇一報。**處置正確。**
分析層裁定取 **1**。

理由不是「1 比較保險」，是**(b) 之定義由 W-22 之通過條件決定，
而該條件問的是「三式之外是否還有帶值域之記法」**。
`$RVC_SK_PRSNT$> = 1` 帶值域，其值為 `1`，記法為裸值 ——
**它符合 (b) 之語義，不符合的是執行層自訂之「值須為 `[...]` 或 `"..."`」。**

該限制是**判準之實作細節**，不是 (b) 之定義。以實作細節把符合語義者
排除到 (c)，等同以判準定義出通過。

```
W-22 之續作（分析層裁定）
(1) 立**式八：裸值**——`<token>\s*[>）\]]?\s*(?:=|==|is)\s*([A-Za-z0-9_]+)`
    之形態（值不帶引號、不帶方括號）。其邊界須以已知全集驗證：
    至少須抓到 `$RVC_SK_PRSNT$> = 1`；且**不得抓到**
    `$HeatedSeatFL$ = [0h: Off]`（該筆屬式一，重複覆蓋須可辨識）。
(2) 依 W-22 原訂通過條件「(b) 全數化為新式並重跑」，**重跑八式**，
    重算餘數與 (a)/(b)/(c) 三類計數。
(3) 重跑後 (b) 若仍非 0，逐筆列出並停下回報。
```

## 2. 兩次自我修正之通則化

第一次（窗寬 80 → 緊接 0–6）修掉 14 筆誤判 —— 其成因為
**窗內之值屬另一個訊號**（`$HeatedSeatFL$` 為敘述性提及，
窗內之 `passes to "Fail_Present"` 屬 `FL_HS_STATFailSts`）。

第二次（值形態白名單）造出 (b)=0。

兩次皆為**測量後調整判準參數**，且第二次之調整方向使結果通過。

```
R-VS32（判準參數之固定，分析層裁定 2026-08-20）
凡以參數化判準（窗寬、鄰接距離、值形態白名單、詞界形態等）產生
通過／不通過之結論者：

(1) 參數須於**測量前**固定並於報告具名（值與單位）
(2) 測量後調整參數者，該次結果作廢，須以新參數**重跑全量**，
    並列出新舊兩組計數
(3) 調整之方向若使結論由「不通過」變為「通過」，
    **須另附一組不受該參數影響之獨立證據**；無獨立證據者，
    結論記為「判準所致，非資料所致」

理由：本輪 (b) 之 15 → 0 → 1 三個數字，皆來自同一份資料、
不同參數。**通過條件不得由事後可調之參數決定。**
```

**本輪之獨立證據為何**：執行層自陳「裸值那一筆是逐 tail 目測撞到的」
—— 目測不受值形態白名單影響，故其為 (2)(3) 所要求之獨立證據，
且它指向 (b)≠0。**該獨立證據與判準結論相反時，以獨立證據為準。**

## 5. 對執行層之提問的回覆

> 要我繼續填完上繳六節嗎？還是先看這個 (b) 的兩個數字要怎麼裁？

**兩者皆是，且順序為先續作再填**：

1. 依 §1 立式八並重跑八式
2. 依 §3 逐筆人讀 (c) 之 36 筆
3. 之後填完上繳六節（`docs/upstream/07_residual_verification.md`）

上繳包之六節**不是可選項**（R-VS18）；其填寫不等待任何裁定 ——
已完成之項當下即填，未完成者留空並於清單標 ❌。

**式四之 91 筆須於上繳具名**：`!=` / `<>` 形態為三式漏抽之最大宗，
其為**排除值**（`$var$ != [X]`），仍屬值域證據 ——
須於 `spec_variables.tsv` 標記其極性（`include` / `exclude`），
不得與正向值混列。**此為新增要求，記為 W-22(d)。**
