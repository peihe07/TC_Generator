## 2. 執行順序之調整：**W-VF55 先於 W-VF54**

V20 §10 之順序為 W-VF54（十條修正）→ W-VF55（Priority 對帳）。
**本包改為 W-VF55 先行**，理由：

W-VF55 之二分結果決定 W-VF54 是否有意義 ——

| W-VF55 之判定 | 對本批之後果 |
|---|---|
| (i) 生成器之 Priority 賦值與 R-VF57 不一致 | **本批非池首，十條作廢重取**；W-VF54 之修正工作全數浪費 |
| (ii) R-VF57 之簇列舉不完整（88 確含該四簇） | 本批確為池首，**W-VF54 之修正有效**；並須補 R-VF57 之條文 |

**故 W-VF54 須待 W-VF55 之結果方得動工。**

**調整後之順序**：`W-VF55 → W-VF54 → W-VF56 → W-VF57`。

（W-VF56 之 A-VF13 全量重跑雖經執行層自判為「最須先辦」，
其結果改變的是 W1／W0 之分布與池數 —— 而池數之改變同樣影響
「本批是否為池首」。**若 W-VF55 判為 (ii)，W-VF56 之結果仍可能推翻該結論**，
故 W-VF56 之重跑結果須與 W-VF55 之對帳並陳，二者不得分開解讀。）
