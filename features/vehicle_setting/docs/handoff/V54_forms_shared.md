```
**理由（其非僅便利，而是已觀察到之缺陷之對治）**：

**一份素材存在二處，其一被更新而另一未被更新時，無人會知。**

**逐項處置**：

| 素材 | 處置 | 依據 |
|---|---|---|
| `Logical Identifiers and CAN Mapping v1_78.xlsx` | **改引 `forms/`** | R-VF123 已准換；本條定其路徑 |
| `inputs/…v1_76.xlsx` | **標記退役，不刪** | 歷史紀錄不追改（R-VF18） |
| `PROXI_HDCC27_R3_20250424.xlsx` | **改引 `forms/`** | 二本 sha256 逐位元相同（上繳 V49 §七-6），無換本風險 |
| **DBC 二本** | **不動，維持 `inputs/`** | **R-VF120 之疑未解（DR-46）** —— `forms/` 之本為 `R1`／`BHCAN2`，改引即實質換本，其非本條所授權 |

**`forms/` 之共用性不蘊含「其內每一檔皆為現行基準」** ——
共用之是**位置**，非**版本之權威**。**DBC 之版本疑義仍待 DR-46。**

**引用路徑之寫法**：以 repo 根之相對路徑
（`forms/…`），**不得寫絕對路徑**（R-VF33：寫死路徑之對治先例）。
```
