## 4. R-VF79 —— 查證與自檢之二則方法規則

```
R-VF79（方法規則二則，分析層裁定 2026-08-24，採納 A-VF23／A-VF24）

**一、範例查證之搜尋鍵須為「測試書寫式」，非「條文用語」。**
條文層之名詞（`propId`／`setProperty`／Android 屬性名）於 TC 中本就不出現，
以其為鍵**必然得 0**，而該 0 不含任何資訊。
**查證前須先問：此鍵若存在，會出現在 TC 的哪一欄？答不出者即為錯鍵。**

**二、自檢之 canon 判準不得另立第二份實作。**
自檢腳本涉及 canon 條文者，**一律呼叫既有之 canon 判準實作**
（現為 `vf230_selfcheck_wvf62.check()`），不得自撰白名單或反推規範。
**自撰者其「通過」為套套邏輯 —— 判準與被驗內容同出一手。**
canon 未涵蓋之專屬項（訊號名／raw 值／標籤格式等）方得另立為增項。

**三、可失效測試之前置斷言**（採納執行層之修法）：
破壞後之副本須與原檔不同，否則判「**此測試本身無效**」，
而非「該檢查項無效」。
```
