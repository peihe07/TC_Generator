## 2. 守衛准立

```
R-VF-甲（句界切分之守衛，分析層裁定 2026-08-24）
【落檔取實測最大 +1，回報實得之號】

**准依上繳 §三之建議增設自檢項**：

  `test_item` 之句號後補空格重切，**若有句可被 `PLUMBING` 刪去則 FAIL`。

**其性質為零成本守衛** —— 全 437 條實測：含「句號後無空格」者 127 條，
**其中因切分失效而留下管路句者 0 條。**

**准立之理由不是它現在會攔到東西，而是它現在攔不到** ——
「缺口存在而現行後果為零」是**現況而非保證**；條文形態一變即可能非零，
**而無此守衛則其發生無人會知**（A-VS106 同型）。

**不改切分式本身** —— 改之將影響全部 437 條之 `test_item`，屬判準變動；
**守衛使其變動之必要性可見，屆時再改成本相同而依據更足。**

**可失效性須實測**：人為構造一條「句號後無空格 ＋ 其後為管路句」之 `test_item`，
該項須 FAIL。
```

## 3. 人讀改為風險分層取樣

```
R-VF-乙（人讀抽樣之取樣原則，分析層裁定 2026-08-24）
【落檔取實測最大 +2，回報實得之號】

上繳 §五-1 自判「8 條 / 437（1.8%）不足以支撐『437 條之節錄取捨皆正確』之推論」
—— **該自判正確，且成因在本層**：V40 §5-3 令「每形態各取 2 條」，
**其為均勻取樣，而人讀之目的為發現機械判準射程外之物。**

**均勻取樣假定風險均勻分布，而風險不均勻分布。**

**改為風險分層取樣** —— 取「最可能藏東西之層」，非等比：

| 層 | 母數 | 取樣 | 何以為高風險 |
|---|---:|---:|---|
| 佔位式（`R-VF101`） | 85 | **5** | 其值非條文所指，為 DBC 列舉首項；`reasoning` 之必要句是其唯一防線 |
| 具名退化（canon §4.3 優先） | 24 | **3** | 其標題無條件子句，區辨僅賴正負向 |
| 含「句號後無空格」 | 127 | **3** | §2 之守衛所管者，其現行後果為 0 之推定須有人讀佐證 |
| `test_item` 長度離群（前 3 長／前 3 短） | — | **6** | 過長＝可能漏刪管路句；過短＝可能誤刪需求句 |
| **合計** | | **17** | ＋ 已讀之 8 = **25 條** |

**不提高至 R-VF76 之 20%（88 條）** —— 其為機械抽樣之比率，
**而人讀之價值不隨條數線性增長；其價值在於所取之層。**

**每條之回報須含**：節錄取捨判（佳／可／缺）＋ 其理由一句 ＋
**「若此條有錯，該錯會被哪一項自檢攔下？」**
—— 末項為本條之核心：**其答為「無」者，即機械判準之射程外，須具名。**
```
