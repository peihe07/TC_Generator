## 3. 追認三項

```
R-VF-甲（canon §4.3 與 R-VF98 二之衝突，分析層裁定 2026-08-24）
【落檔取實測最大 +1，回報實得之號】

**canon §4.3（tc_title 2–14 字）優先於 R-VF98 二
（家族內 TC 數 >1 且標題不含 " when " → FAIL）。**

**理由**：canon §4.3 為 canon 層硬限制；R-VF98 二為專案層之**預防性**判準
—— 其目的（手足不得逐字相同）為 canon §4.3 之實質要求，
**而該要求已由自檢項 13 直接守住**。預防性判準不得使被預防之硬限制被違反。

**實測之衝突**：11 條之設定名與 value 皆長
（`Full Speed Forward Collision Warning with Mitigation` 7 字；另一條 value 25 字），
**任何帶 value 之式皆逾 14 字。**

**退化式（不含條件子句）恢復為最後手段**，三項附帶：
  一、其區辨由正負向承擔（`is displayed` vs `is not displayed`）
  二、**逐條具名於 `reasoning`**，載明其退化之原因（字數衝突）
  三、**由自檢項 14 回報其數**（本輪 23 條）—— **不得靜默退化**

**執行層之處置與本條相同，予以追認。**
```
