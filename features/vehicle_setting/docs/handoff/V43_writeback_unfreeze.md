## 5. R-VF-乙 —— 首次寫回之不可逆性

```
R-VF-乙（首次寫回之階段化，分析層裁定 2026-08-24）
【落檔取實測最大 +2，回報實得之號】

**寫回為不可逆操作**（其改動交付路徑之工作簿），
**故首次寫回一律 dry-run 先行，其預覽表經覆核後方得實寫。**

**dry-run 之意義不在確認格式正確，而在使「寫進去會變成什麼」
在寫進去之前可見。** 440 列一次寫入，其錯若於寫入後方見，
回復之成本與 R-VF14（不回溯已交付）之拘束將同時生效。

**實寫之授權須為獨立之一次裁定**，不得由 dry-run 之通過自動導出。

**本條及於其後之每一次「首次」** —— 即凡寫回之目標工作簿或欄位映射
有變者，其首次寫回同受本條拘束。
```
