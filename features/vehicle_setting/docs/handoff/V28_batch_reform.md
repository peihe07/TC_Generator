## 1. R-VF76 —— 批次規則改制（Pei 裁定 2026-08-24）

```
R-VF76（VF230 量產階段之批次規則，Pei 裁定 2026-08-24）

**pilot 階段**：維持一批一上繳、前批未覆核不得開下批。

**量產階段**（pilot #2 通過後起算）：
  批量        **50 條／批**（分析層自裁，R-VS30）
  上繳節奏    **連續 3 批（150 條）一次上繳**
  覆核        分析層**抽樣 20%**（每 150 條抽 30 條），不逐條讀
  抽樣方式    每批各抽 10 條，涵蓋該批之全部書寫形態；
              形態數 >10 者以形態優先，同形態內取首條

  **抽樣中出現任一 blocking defect → 該 150 條全數退回，
  且下一組恢復一批一上繳，直至一組零 defect 方回復本制。**

**改制之理由**：現制下 621 條需 63 輪。pilot 之目的為驗證書寫形式，
形式定形後逐批全讀之邊際價值低於其成本。**抽樣之風險由退回機制承擔。**

**不改者**：canon §1.2 之 pilot review（分層取樣、三分類、
done-region check）於 pilot 階段不變；R-VF26 之寫回凍結不變。
```
