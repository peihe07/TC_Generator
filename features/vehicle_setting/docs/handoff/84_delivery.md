R-VS29／R-VS73 管的是**判準改變後之數**，**不管判準改變後之舊產物**。

```
R-VS77（分析層裁定 2026-08-23）
凡新立或修訂之條文，其影響及於**已產出之 TC** 者，
於該條文落檔之同輪，**須對全母體回掃一次**：

  (1) 列出符合該條文之新判準而**現行產物不符**者，逐條具名
  (2) 其修正與新產出之 TC 同輪為之，**不得留待下次抽樣發現**

**「已通過 pilot」不豁免回掃** —— pilot 覆核之基準為當時之條文，
條文變更後其結論不自動延續。

同型另一例：80 包對 `-021`／`-022` 之修正未推廣至 batch23（83 包 D-2）——
**一為往前未回掃，一為往後未推廣，其成因同一。**
```
