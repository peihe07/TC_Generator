```

```

**一項分類先例須具名**：`PROXI $X$ is set to "Present"` 之值 `Present`
會命中「硬體周邊」之 `\bpresent\b`。**首版依序比對而誤歸**。

**值不得決定其類別**（其為配置之設定，非硬體之在位）。

**可失敗性實測**：插入 `The user has an account`（不可歸入四類）→ **rc=1**，
