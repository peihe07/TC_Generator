## 7. ⚠ 自檢三批全 0，而人讀抽驗仍抓到一條（A-VF26）

生成後逐形態各讀一條（4 條），於 **seq 268** 抓到：

```
條文：When the customer chooses to **enable** the Suspension Service Mode setting …
      … value = [OFF] … Then … update the … status to **OFF** …
```

**動作句之動詞與其值／結論句極性相反。**

**任何「內部一致性」之檢查都攔不到它** —— 該 TC 之各欄彼此完全一致
（前置 On、驗 Off、標題 Off），**其不一致在條文與 TC 之間，
而 TC 忠實反映了條文的結論句**。

**處置依 V23 §4.2**（A-VF18 之處置）：**以結論句為準**，
於 Remarks 逐字具名其不一致與 DR 編號，**不自行調和**。已開 **DR-38**。
**偵測式已補入生成器**（`chooses to (enable|disable)` 與值之極性比對）——
**其為已知集合，非全集**。全母體可抽之 497 條中，此形態 **2 條**
（另一條不在本組 150 之內）。

**本層之獨立判斷**：**這是本輪最該記的一件事。**
自檢與 canon 判準在三批 150 條上皆報 0，而缺陷由**讀四條**得之 ——
**與 A-VF13、A-VF24 同型：「做一件具體之事」所得，非由重跑檢查所得。**
