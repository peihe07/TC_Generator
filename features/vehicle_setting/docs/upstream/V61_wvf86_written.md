## 二、W-VF86.1 之空跑**攔下一個真缺陷** —— 閘 4 首跑即崩

**其非「驗證通過」，而是「驗證查出問題」**：

```
閘 1／2／3 全過 → 閘 4 崩潰（非「停」，而是 XML 解析例外）
  unbound prefix: line 3618
```

**成因**：`<extLst>` 內用 `x14:`／`xm:` 前綴，**而 openpyxl 重寫 `<worksheet>`
根元素時丟棄了其 `xmlns:` 宣告**。只補 `<extLst>` 而不補宣告，其 XML 不合法。

**其亦更正本層先前之一項宣稱**：上繳 V45 §三稱替代路徑「**已驗其形**，未驗其用」
—— **而其時只驗了 `x14dv` 之元素數與 openpyxl 可讀**（openpyxl 之解析較寬容），
**未驗 XML 之合法性**。**該宣稱過強。**

**已修**：補回時一併補 `xmlns:` 宣告，並以**嚴格 parser 自驗，不合法即停不寫出**。

## 四、W-VF86.6：`Slovenian` 之消失 —— **換本修正了一個既有污染**

```
舊 FDCAN8 R5    msg_id 1443｜**22 值**｜無 raw 22
```

**故換本非僅換本，其一併修正了該污染。** 新本之 22 值為正。
**不開 DR** —— 其原因已查明，非未決之問題。
