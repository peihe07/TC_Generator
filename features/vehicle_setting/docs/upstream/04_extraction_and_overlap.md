> **判準化之價值在此得到證明** —— 若無 C3 判準，這 6 筆會混進「待判 16」而看不出是回歸。

## 4. 本輪實際使用之掃描條件（canon §5a 條 1／2／4／5）

| 對象 | 條件 |
|---|---|
| LID 儲存格切條目 | **換行優先**；無換行者以**連續二空白**切（`\s{2,}`）。⚠ 單一空白不切 —— `CAN-B FD` 之形態需換行才分得開 |

| LID 來源 | **自 `inputs/*.xlsx` 原始儲存格讀取，`str(v)` 保留換行**（不做 `norm()`）。⚠ `data/lid_map.tsv` 為 W-14 之有損中介，本輪不再作為輸入 |
| 值正規化 | 剝 `Nh: ` 前綴；` / ` 切別名；`\s+`／`_` 併單一空格；轉小寫 |
| 歸因判準 | `scripts/attribution.py`；C3 以值內殘留 `bit signal`／`STATFailSts`／`STATSts` 偵測；C2 以差集全為 `fail[_ ]?(not[_ ]?)?present` 偵測 |
