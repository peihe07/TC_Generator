## 6. 獨立判斷：本包是否仍有該驗而未驗者

**有，五項：**

1. **`-014` 之 false pass 是我在「值未解」與「驗證目標即該值」之間取了可寫的那一半。**
   procedure 只差 step 1 之值而 ER 逐字相同 —— **這個對比一擺出來就無可辯解**。
   R-VS71 令「值未解不阻塞生成」，但它同時說「該處寫 PENDING，其餘照寫」；
   **我照寫了其餘，卻沒把該處寫成 PENDING，而是換了一個能通過的斷言。**

2. **A-VS158 是分型式第二次因 `$` 之有無而失準**（前次為 A-VS111：條文自帶值者不過閘）。
   **`$` 之有無在本母體不是語義區別，而我兩次以其為判準。**

3. **R-VS75 之首次回流列出六項直接往返裁定** —— 其中五項分析層從未見過，
   而它們已經影響了 38／40／47／48／50 五輪之產物。**回流機制立得太晚。**

4. **最終總量 245 三輪未變**（50 輪 242 → 51 輪 245 → 52 輪 245），
   而已生成自 159 增至 178。**預估之穩定不代表其準** ——
   未生成之 64 leaf 其預估仍以 v3′ 施於條文，**未經任何抽驗**。

5. **母本停在 241 列而已生成已達 178 TC／173 leaf。**
   下次寫回之列數將為 178 ＋ 64 ＝ **242 列**，**x14 之修復範圍又要再改一次**。
