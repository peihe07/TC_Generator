## 三、**三處前提不成立**；其二已由本層消解，第三處待裁

### 3.1 2 條之「事實抽不出」為**抽取式之缺陷**，已修，二條回收

**首報為「PROXI 型而條文未帶值」。逐字人讀其條文後，該判斷為偽**：

```
SWE1-VC-SuspensionServiceMode-002   HMI receives the value as "Absent" via signal,
SWE1-VC-SuspensionServiceMode-003   HMI receives the value as "Present" via signal,
```

**條文帶值，且其形態即抽取式所認之第 (b) 式** ——
**惟其值帶引號，而字元類 `[A-Za-z0-9_ ]` 不含 `"`，比對遂失敗。**

**其失敗回報為「條文未帶值」而非「未比中」** ——
**`A-VF25`／`A-VF27`／`A-VF13` 同族第四例**：抽取式與資料之實際形狀不合，
而其失敗呈現為關於資料之結論。

**其被查出之途徑須記**：本層首版將此列為 §九之「該驗而未驗」第 2 項
（「未逐字人讀該 2 條之條文，不能排除其為同族第四例」）——
**逐字人讀之，即是第四例。** **一個自具名之未驗項，其被驗即出問題。**

#### 3.1.1 `R-VF82` 之兩側量測（放寬前必為之）

```
全選池 574 條掃描：寬式命中而現行式漏者 **3**
  SWE1-VC-SuspensionServiceMode-002／-003    ← 本次標的
  SWE1-VC-PowerUnit-013                      ← **已寫入**，其走 `value = [kW]` 另一路徑，
                                                寬式命中為巧合，非受害者

放寬（字元類加 `"`）之效果
  偽陰回收   **2**（恰為標的）
  偽陽引入   **0**
  量產側     facts **501 → 501**，**逐條比對相異 0**
  九批自檢   **0 0 0 0 0 0 0 0 0**（回歸）
```

**只加引號、不加括號** —— 二者皆足以回收，取其小者。

**值之引號另行剝除**：條文之 `"Absent"` 與其餘條文之 `Absent` 為同一值，
**引號為引述標點非值之一部**；不剝則 TC 之書寫式產出 `is set to ""Absent""`。
**只剝成對包夾者**，值內之引號不動。剝除後 `value = 'Absent'／'Present'`，
`negative` 旗標分別為 `True`／`False`，與條文之結論句一致。

## 五、W-VF90.5 —— 成因與 **A-VF32**

**成因為二行程式**：

```
vf230_wvf69_facts.py:389      body = pool - pilots
vf230_wvf69_isolate.py:99     body = pool - pilots - iso
```

**其前提為「pilot 之產出已在交付本內」，而該前提從未成立** ——
二 pilot 之 TC 只存於 `generated/vf230_pilot{1,2}.json`，
**而 `data/vf230_batches.tsv`（寫回與自檢之單一權威清單）不含之**，寫回遂不及於其。

**其未被任何檢查攔下之三因**（已登記於 `A-VF32`）：

1. **扣除方不讀該清單，二者無交集** —— 一條被扣除又未列入清單者，
   **於自檢之視野中根本不存在，故不會呈現為「缺」。**
2. 隔離表與去重表各自完備，**而「既不在此亦不在彼」之第三類無表可載。**
3. 每批自身連號無斷點，**逐批之檢查必然全綠**（`A-VF29` 同型）。

**通則（已入 A-VF32）**：凡自母體扣除一批而其產出另循他途納入者，
**扣除方與納入方須讀同一份清單，或另立一項對帳使二者之差可見**；
二者若分屬二處而無對帳，**其差額之大小與其存在皆不可見。**
