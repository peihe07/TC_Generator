## 6. 獨立判斷：本包是否仍有該驗而未驗者 —— **有，六項**

1. **W-29 之 174 個 `yes` 中，`comfort_leaf_ids` 為 Layer 3 層級之對應，非逐 leaf 對應。**
   同一 Layer 3 之所有 leaf 指向同一組 Comfort leaf。
   **未驗證該組內每個 Comfort leaf 是否真與該本 feature leaf 之行為對應** ——
   委派句若逐 leaf 指名，其精度不足。

2. **W-29 之 46 個 `no` 未逐筆人讀。** 其判定為「六組功能詞皆不命中」，
   而 06 輪已證「功能詞清單不全會產生假陰性」（A-VS34 即此）。
   **`no` 之 46 筆可能仍有漏，同一形態。**

3. **W-22(d) 之極性表僅及於 CFTS044 側。** DBC 之 `VAL_` 與 LID 之 `Format`
   本就是值列舉，無極性問題；**但 W-8／W-19 之比對是把 CFTS 側之混合集合
   對比 DBC／LID，該比對之結論未依極性重算**。
   **DR-8 與 DR-12 之論據因而仍建立在未分極性之集合上**（08 輪已報，本輪未修）。

4. **式八之「裸值」與「表格式」（式六）之邊界未相互驗證。**
   二者皆匹配 `= 值` 而值不帶括號引號；其差別為式六要求值以特定名詞結尾。
   **重複覆蓋之筆數未量。**

5. **W-32(d) 之交叉驗證兩側皆以 7 位數 id 為鍵。**
   若某 id 於 SYS2 與 docx 指向不同條文，本驗證看不出來 ——
   其驗的是「章節歸屬一致」，非「id 指向同一條文」。
