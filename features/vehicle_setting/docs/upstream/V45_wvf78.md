## 三、x14 之破壞：實測（R-VF113 二，引用不得代替量測）

於副本上以 openpyxl 開檔→存檔，前後比對 xlsx 內之 XML：

```
                     dataValidation   x14:dataValidation   extLst
存檔前                      4                  2               1
openpyxl 存檔後              4                  0               0    ← **x14 被移除**
```

**本條之推定成立** —— 一般 `dataValidation` 不受影響，**遭移除者為 x14 擴充**。
openpyxl 之警告逐字：`Data Validation extension is not supported and will be removed`。

**替代寫入路徑（已實測其可行）**：openpyxl 存檔後，以 `zipfile` 自**原檔**取
`<extLst>…</extLst>` 片段（本檔為 `xl/worksheets/sheet6.xml`，512 字元），
補回新檔之同名項，置於 `</worksheet>` 之前。

```
原檔              dv 4｜x14dv 2｜extLst 1
openpyxl 存檔後    dv 4｜x14dv 0｜extLst 0
補回 extLst 後     dv 4｜x14dv 2｜extLst 1   ← 恢復
補回後 openpyxl 可讀：✅（分頁數 10 不變）
```

**其限制須具名**：本實測驗的是 **XML 元素之恢復**，
**未驗「Excel 開啟時下拉是否真的可用」** —— 該驗證需 Excel，本環境無。
**故該替代路徑為「已驗其形，未驗其用」。** 實寫前是否須人以 Excel 開檔確認，**請裁。**
