## 二、【阻斷】B 欄為公式，非可寫之序號

### 實測

```
repo VF230    B10 = '=IF(ISBLANK($D10),"",ROW()-9)'   … 至 B246（237 列）
                                                       B247 起**無公式**
repo CFTS044  B10 = 同一公式                            … 至 B246
交付 CFTS044  B10 = '1'（**硬值**）                      B252 = '243'
```

**三項推論**：

1. **B 欄之值為 `ROW()-9`，自列 10 起算 1** —— **各本獨立，非跨本共用之序號空間。**
2. **交付路徑之 CFTS044 其 B 為硬值 1–243**，係因其有 243 列資料
   （公式已於某時被轉為值）—— **其 243 不是「佔用了 243 個號」，
   而是「該本自己有 243 列」。**
3. **`R-VF83`（自 238 起）與 `R-VF114`（實測導出取二本最大 +1 = 244）
   之事實前提因而不成立。** 本層上輪之「實測導出」較「寫死 238」為佳，
   **而二者所依據之模型（共用序號空間）同樣為假。**

### 其後果

**照 244–681 寫入 B 欄，須覆寫該 237 格公式為硬值**，且

- **列 247–447 之 B 欄無公式**（438 列須寫至列 447），其行為與前 237 列不一致；
- 覆寫後**該本之自動編號機制即失效** —— 日後增刪列不再自動重編。

**本層不自行決定。三問請裁**：

1. **B 欄是否應寫入？** 抑或**留空由公式自算**（其值將為 1–438，非 244–681）？
2. 若須寫入 244–681，**覆寫公式為硬值是否為所欲**？
   （交付路徑之 CFTS044 已是硬值，**其或為既有慣例**——本層未查其轉換之時點與原因。）
3. **列 247 起無公式**一事如何處置？（補公式／全部寫硬值／其他）
