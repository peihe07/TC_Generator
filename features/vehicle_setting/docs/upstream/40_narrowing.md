## 2. 不符項目（不自行調和）

### 2.1 W-133 之錨點初版**兩側皆未命中** —— 解析失準，非判準失準

`carry_test_w133.py` 初版對兩側皆回報「兩欄組皆不能承載」。追因為 `fmt` 之解析：

| 失準 | 症狀 |
|---|---|
| (a) 換行為**字面之 `\n` 兩字元** | `0 = Not_Pressed\n1 = Pressed` 讀成單一值，基數 2 → **1** |
| (b) 單一儲存格**綑綁兩訊號之列舉** | `HeatedSeatFL` 之 `0`／`1` 被後段 `Fail_*` 覆寫，四階 → **2 值** |

**修正後兩側皆命中。** → **A-VS151**

**值得記其被抓到之方式**：兩側錨點皆有明確預期，初版**兩側皆回報同一結論** ——
該一致之錯誤即解析失準之訊號。**若只設必命中側**，(b) 之偽陰性會被讀為
「High 欄組確實不能承載」而**逕行降欄組並標 `impl_gap`** —— 其結果看似正確而實為誤判。
**R-VS54 之「兩側皆須有標的」於本輪首次實際擋下一次誤判。**
