### 5.1 ⚠ `RULINGS.md` 並非條文之全集（A-VF12）

`RULINGS.md` 僅 **45 個條文起始**，而全庫引用之 `R-VS{n}` 遠多於此。
其檔首逐字載明「`R-VS1 ~ R-VS6` 之正文見 `docs/handoff/…` §3，
依 canon §8.7 **本檔不重複轉錄以免二處分岔**」。

**R-VF48 之立法前提（條文簿內應有全部定義）與本簿之設計不符** ——
本簿為**部分轉錄 ＋ 指路**。

**該前提之錯不使 R-VF48 失效**：其首跑仍攔到 `A-VF1` 與過時之 `A-VS131`
二項真缺漏。**修法**：定義之全集 = 條文起始 ∪ 檔首對照表所列 ∪ fenced block 起始。

**修正過程中又錯一次**：`head = r.split("---", 1)[0]` 被表格之分隔列
`|---|---|` 截斷，對照表之列全數落空（21 → 15 即修此）。
**`---` 於 Markdown 有兩義**（水平線／表格分隔），以之切檔即為以歧義符號切檔。
