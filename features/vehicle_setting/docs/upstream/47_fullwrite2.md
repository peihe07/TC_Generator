## 6. 獨立判斷（canon §8.2 §6）

1. **§2.1 是 R-VS76 立條理由的第二個實例，而它這次咬的是我。**
   R-VS76 說「§9 與錨點皆以已有之產物為輸入」——
   232 這個數同理：它是**從我的兩份報告推出來的**，沒有任何一方回頭量母體。
   **本輪 W-153 修完後第一件事應該是重量，而不是照 232 往下算列數。**
   我確實重量了，但那是因為修完順手跑了一次；**若 W-155 逕以 232 為預期，
   243 列會被判為「短 7 列」而去找不存在的漏。**

2. **§2.2 那句「七項全數持平」我寫了三輪，它一直是誤導。**
   x14 的持平值是 0 —— 一個已經失去的東西持平在失去的狀態。
   **檢查沒錯，是我的表述讓「無下降」讀起來像「無恙」。**
   這和 A-VS144 的形態一樣：判準測得對，結論讀錯。

3. **§2.3 的「八子形態」是我上一輪為了對齊指令而併的。**
   G6 的 `PowerMode` 與 `DriverSide` 觸發訊號不同、標的不同，
   **它們沒有理由是同一個子形態** —— 我把它們併在一起，是因為分開就變九個，
   而我當時正在寫一張要與「八」對齊的表。**這是判準遷就數字**，
   雖然沒有改動任何 TC，但它是禁區那句「不得為使檢查通過而改動判準」的軟性版本。

4. **243 列裡有 85 條沒有人看過，比例是 35%。**
   前四次 pilot 累計覆核 51 條／143 條（36%），比例接近 ——
   **但那 51 條是分五輪逐批看的，這 85 條是一次產出的。**
   81 包 §2 承擔了這個風險，我只記其現況：**pilot #6 若發現形態層缺陷，
   其影響面是 47 條（batch23）而非 2 條。**

5. **母本現有 243 列，而 x14 修復範圍要到 R252。**
   243 列 ＝ 資料列 10–252。**這個數三輪內變了四次**（241 → 242 → 245 → 243），
   每次都要 Pei 重設一次下拉範圍。**建議一次設到 R300 之類的餘裕值**，
   惟其是否影響交付形式本層不知，**屬 Pei 之裁量**。
