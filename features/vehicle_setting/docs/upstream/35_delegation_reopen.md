## 2. 不符項目（不自行調和）

### 2.1 錨點 1 命中 15/16 —— 第 16 條之阻塞非 delegate

`SWE1-VC-HeatedSteeringWheelManagement-035` 維持 `generatable = no`，
其理由為「未解值位於後件」，未解值為 **`HSW_StatFailSts = Fail_Present`**。

追因：`bus_domain()['HSW_StatFailSts']` 與 `lid_column_domain()['HSW_StatFailSts']`
**皆為空集**，而**基線 DBC 之 `VAL_` 有其完整值域**（`0 "Fail_Not_Present" 1 "Fail_Present"`）。

**此為 A-VS102 之同型遺漏** —— 該 anomaly 補收了四個 `*_HS/VS_STATFailSts` ＋ `EngineSts`，
**漏收 `HSW_StatFailSts`**。且 BACKLOG 之 **B-02** 其解凍條件逐字為
「(b) HSW 相關 leaf 進入生成時」—— **本輪該條件已成立**（R-VS40(b)，具名 leaf 如上）。

**本層未補收**：補收會改動全量分級，而本輪之作業範圍為四條新裁，補收不在其列。
→ **A-VS137**

**錨點之判讀**：15/16 之未達 100% **不是 R-VS59 未生效** ——
其餘 15 條皆由 `no` 轉 `yes`，即 delegate 之扣除確已去除。
**本層不將其記為「錨點通過」，亦不記為「併入未生效」。**

### 2.2 W-112 之「查得 174／查無 0」是 Layer 3 群層級，不是畫面層對應

`delegation_lookup.tsv` 之 `comfort_leaf_ids` 為 **R-VS7(a)′ 之功能群指名**
（Layer 3 群，非單一 leaf id），故本表之比對粒度即 Layer 3。實測：

| 指標 | 值 |
|---|---:|
| 標的（`delegate ∈ {yes, pending}`） | 174 |
| 每 leaf 之 Comfort 命中條數 | 只有三種值：**1／5／17** |
| 相異 `comfort_leaf_ids` 組合 | **3** |
| Comfort 037 之 Functional 條文 | 403 |
| 　其中含 heated／vented seat 者 | **20** |
| 　　其中含 fail／error／malfunction 者 | **0** |

**即：174 個 leaf 實際只對應 3 組 Comfort 條文；而本輪所需之失效層內容，Comfort 有 0 條。**

**「查無 0」不可讀為「Comfort 素材足以支撐 R-VS59(2)」** ——
其只證明「該功能群於 Comfort 有條文」，未證明「該 leaf 之特定畫面行為有逐字來源」。
**batch16 之 10 條即其反例**：全數為失效狀態，畫面層斷言一律標
`PENDING: DR-5-B`（R-VS59(4)）。→ **A-VS139**

升級門檻「查無 > 查得」因而**在本判準下永不命中**，其偵測力為 0。
**建議 W-112 之判準改為逐 leaf 之行為層比對並附錨點。**

## 6. 獨立判斷：本包是否仍有該驗而未驗者

**有，五項：**

1. **R-VS59 解鎖了 34 個 leaf，但它所承諾的「畫面層取自 Comfort 素材」在本輪一次都沒兌現。**
   batch16 的 10 條全數 `PENDING: DR-5-B`。**該條之上半（一律產 TC）已生效，
   下半（內容從哪來）尚未被任何一條 TC 證實。** 若 Comfort 素材對失效層確實為空，
   則這批 TC 交付時的實質內容只有 CAN 注入，畫面層是空的。

2. **兩個錨點都沒有乾淨地通過**：其一 15/16（第 16 條另有原因），其二根本無標的。
   依 R-VS54，「無標的之錨點」與「0 項違規而無錨點」是同一件事 ——
   **R-VS62 之解鎖目前沒有任何證據支撐**。

3. **W-112 的判準沒有偵測力。** 其升級門檻「查無 > 查得」在 Layer 3 粒度下永不命中。
   本輪之所以發現問題，靠的是 W-113 撞到「Comfort 之 seat 條文含 fail 者 0」——
   **是作業撞出來的，不是判準查出來的。**

4. **編號衝突第三次。** 兩條線共用 `RULINGS.md`／`ANOMALIES.md`／`DATA_REQUESTS.md`
   而無預留機制，本輪我三筆中有兩筆撞號、上一輪四條條文全撞。
   **這不是偶發，是結構問題。**

5. **A-VS137 之補收會改動全量分級。** 其為 B-02 之解凍標的且條件已成立，
   本輪僅具名未做。**下輪若做，126/2/109 → 137/2/98 這條對照鏈須重新錨定。**

**本輪無「該驗而漏驗」之作業項** —— 三項作業（W-111／W-112／W-113）皆執行且皆有結果。
