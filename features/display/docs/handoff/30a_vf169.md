## 三、它給了三件東西（皆為證據，非權威）

### 3.1 `RADIO_B3.RQ_DISP_INTS` —— DR-DM5 之直接證據

逐字：`RADIO_B3.RQ_DISP_INTS` ／ `Requested display intensity`。

DR-DM5 之標的為規格所載之 `CCDMF_RQ_DISP_INTS` 於 DBC 查無。
本檔給出 message 名 `RADIO_B3`。

**拘束（R-13／R-DM43）**：**不得以 `RADIO_B3.RQ_DISP_INTS` 代入規格
原名。** 規格原文所載之訊號名一律保留，DBC 對應缺漏登記 DR 向上游查詢。
本項僅作為 **DR-DM5 之附件證據**。

該訊號之份量：`$RQ_DISP_INTS$` 為 `{4943099}`（51–55°C 降亮度）與
CFTS_020 `{4820284}`／`{4821592}` 共同引用者 —— **兩套流程都用它。**

### 3.2 `TGW_DISP_STATSts` 之 message 名 —— DR-DM9(b) 之一半

逐字：`TELEMATIC_DISPLAY2.TGW_DISP_STATSts`（B/BH-CAN）／
`TELEMATIC_FD_4.TGW_DISP_STATSts`（FD-CAN8）／
`TGW Display status`。

**只給 message 名，不給 `VAL_` 標籤。** DR-DM9(b) 之核心
（`[DISP_NORMAL]`／`[DISP_REAR_CAMERA]` 對到哪個 raw）**仍然無解**，
A3 之阻斷不變。
