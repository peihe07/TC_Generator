### 4.1 我上輪的推測是錯的，而結論碰巧相同

上繳 07 §11 第 6 項我寫「SYS2 之 `Description` 是散文，底線少見，
但我沒有實測過這個判斷」。本輪實測：

| 項 | 實測 |
|---|---|
| FR 母體 80 列中 `Description` 含底線者 | **66**（82.5%） |
| 含底線之相異 token | **40** |
| 其中與 `rear`／`cam` 相關者（不分大小寫） | `DISP_REAR_CAMERA` 一個 |

**底線在 SYS2 側非但不少見，反而是多數列都有。** 那些 token 是識別碼
形態之訊號／值名（`TGW_DISP_STAT`、`CM_TCH_STAT`、`CCDMF_RQ_DISP_INTS`
…），不是被底線連起來的散文詞組。

正規化加 0 個候選之**真正原因**是：唯一相關之 `DISP_REAR_CAMERA`
正規化後為 `DISP REAR CAMERA`，與展開後之 `Rear View Camera` 仍不等
（少 `View`、多 `DISP` 前綴、大小寫不同）。

> 結論（0 個）與我推測時所預期的相同，但**理由完全不同**。
