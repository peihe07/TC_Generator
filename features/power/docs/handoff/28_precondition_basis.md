```
[R-P204] `pre_conditions` 之依據判準有別於 `expected_result`。
         G82 擴充後觸發 25 項，其中 14 項為
         「`pre_conditions` 引用本 leaf 未載之訊號」。
         **不得逕判為真陽性。**

         二欄性質不同：
         - `expected_result` 為**判準** —— 其所斷言之每一事實
           皆須有本 leaf 錨點之規格依據；越界即為造值（§8.4.1 / §8.4.2）
         - `pre_conditions` 為**設定** —— 依 §4.4 其內容為
           起始狀態與環境。指名本 leaf 未載之訊號，
           若該指名僅用以描述**狀態**，即為合法之環境設定；
           若用以斷言**行為或時序**，方為越界

         判準（逐項適用，不得整批判定）：
         （a）該項僅陳述某訊號／參數於測試開始時之**值或狀態**
              → **非越界**，為合法環境設定
              例：`TLM_Status.Info reads "Standby"` 作為起始狀態
         （b）該項斷言某**行為之發生、時序或結果**
              → **越界**，須移除或改寫為狀態陳述
              例：`TLM 於 X 秒內完成開機` 作為前提
         （c）該項為 §8.5 所禁之環境穩定性前提
              → 依 R-P88 處置（與本條無涉，另計）

         處置：14 項逐項依 (a)/(b) 判定並回報依據；
         判為 (b) 者逐條修正。
         **G82 對 `pre_conditions` 之規則須依本條調整**，
         不得沿用 ER 之判準。
         裁決者 Pei，逐字依據：「出」。
```
