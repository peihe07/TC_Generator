## 四、B4 —— `GLUED_OR_RE` 查明（R-P258 / G180）**不因此改值**

### 4.1 (a) 增量之組成

增量之成因先查明：加 `re.I` **使左側之 lookbehind `[a-z0-9"']` 亦匹配大寫字母**。

| 項 | 數 |
|---|---|
| 現行命中（區分大小寫） | **2** |
| 加 `re.I` 之增量 | **2406** |
| 　左鄰為字母 → 某單詞之**字尾（誤命中）** | **2406** |
| 　左鄰為引號或數字 → **可能之真黏連 OR** | **0** |

逐一判讀 80 個大寫增量之語境，來源全為
`DOORS` / `NORMAL` / `U_APPLICATION_LOW_TO_NORMAL` / `U_APPLICATION_HIGH_TO_NORMAL` /
`SWITCH_OFF_DOOR` / `FOR`（如 `REQUIREMENTS FOR E/E COMPONENTS`）之字尾。**無一為真黏連 OR。**

現行 2 個真命中之形態為 `IF PhoneCall.Info == "Active"OR IF previous internal …` ——
其左鄰為 `"`，與誤命中之左鄰為字母**形態相異**，
**即現行之 lookbehind 設計正確地區分了二者**。

**⚠ 判準於分析中訂正一次（並陳兩版）**：初版要求「左右**皆**為字母」方判詞內，
致 `SWITCH_OFF_DOOR is`（右鄰為空格）等 **12** 個被誤列為「非詞內」——
即誤報 12 個可能之真黏連 OR。**左鄰為字母即足以判定為詞尾，右鄰無關**；訂正後為 0。
**偏誤方向為誇大返工面**（12 個假警報會觸發 G113 全批重跑），依 R-P187 明載（A-PW214）。

### 4.2 (b)(c) 返工面

**此為 36 包「增幅大不等於應改」之具體實證**（A-PW213）。
