## 十、執行層自判：本包仍有該驗而未驗者

**有，四項。**

1. **`COSMETIC_RE` 之偽陽性係因 B3 之全面實測才查出，而非因其影響面被察覺。**
   其影響為 3 條改值錯誤 —— **恰是 R-P280 所預期之「影響面小者不會被察覺」**。
   **反面推論**：本包只測了**裸詞**謂詞（28 個）；
   **其餘 52 個非裸詞謂詞未以同法實測**，其中是否另有同型者，本包無從知。
2. **B3 之抽樣為每謂詞 3 條。**
   `COSMETIC_RE` 之 573 次命中中抽 3 條 = 0.5% ——
   其偽陽性所以被發現，是因抽中之 `Brand_Configuration _2` 恰為該形態；
   **若抽樣未中，該 3 條改值錯誤不會於本包被發現**。
   **抽樣 3 條之設定來自條文（R-P280(b)「至少 3 條」），執行層未加碼。**
3. **`axis` 224 條中 188 條（187 已改 ＋ 1）無素材。**
   36 條素材之覆蓋率為 16.1%，且**分析層自 38 包起連續三包未讀** ——
   §K 第 1 項已令 42 包必須讀畢。
   **本包依 R-P272 之先例改值先於複核，而該先例正如 §K 所慮，
   已連續二包（40、41）被援用。**
4. **G197 之盤點為執行層自列，其完整性無外部檢查。**
   「阻斷／不阻斷」之判定亦由執行層為之 ——
   若漏列某項或誤判其為不阻斷，**無機制可查**（A-PW252 之同型）。
