**成因二類**：
1. **ITD 內聯**（`-006` / `-008` / `-013`）—— R-P366(a) 令內聯，而該三條之 ITD 含多個並列值，
   內聯後末步變長。⚠ **67 包曾實測「回指步從來不是末步（0 / 163）」**，
   當時據此判 R-P366(b) 之拆步條款無觸發；**B5 之 R3 改動了步序，該前提已不成立**。
2. **複合觀察目標之 `;` 串接**（`-119` / `-120` / `-135` / `-187`）——
   R-P395(c) 允許「同一步內以 `;` 續列或拆步」，本層一律取 `;` 續列，
   落在末步者即逾限。全案含 `;` 串接且逾 18 字之句共 **48 句**，
   其中 **7 句落在 ER 末步** → 即本項。

**處置建議（不逕行，交分析層裁）**：依 **R-P366(b)** 明文
「內聯後末步逾 §5.2B 者**不得刪減資料以合字數**；改為拆步」——
七條之末步拆為二步，ER 對齊。**其餘 41 句不在末步，§5.2B 不約束，不動。**
