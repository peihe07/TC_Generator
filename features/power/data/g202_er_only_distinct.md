# G202 —— 三欄全同而 `expected_result` 相異（R-P288）

> 判準：`pre_conditions` / `input_test_data` / `test_procedure` **三欄逐字全同**而 `expected_result` **相異**。
> **G178 抓不到本形態**（其要求 ER 亦相同）。
> 其意義：**依內文執行，二條之操作完全相同，而所觀察者不同** ——
> 或應合為一條多 ER（§5.7），或內文漏寫其區分（R-P257 之形態）。
