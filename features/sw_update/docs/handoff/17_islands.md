## 三、裁決條文（抄入 RULINGS.md，逐字）

```
R-SU20（Layer 2 正確性之最低檢查 —— 孤島列）

R-SU10 v2 之三重閉合全屬**完整性**維度：其證明「311 列被無重複、
無遺漏地分完」，**不證明分得對**（上繳包 15 §6.2）。
正確性維度之條文原僅有切分原則 3、4，二者皆不可機器化。

裁定：**孤島列檢查**為 Layer 2 正確性之最低機器化檢查，
每次 Layer 2 之切分或變更後必跑。

(a) **定義**：於同一 Heading 群內，某列之 Test Set 與其**文件序之
    前鄰與後鄰皆不同**者，為**孤島列**。

(b) **原理**：037 之列序即 CFTS 之文件序，同一能力之列在文件中傾向相鄰。
    「文件序相鄰」為**與標題完全獨立**之信號（來自 037 之排列，
    不來自任何人之措辭）。故一列若被自連續段中抽出，
    **其依據必須強過「相鄰」這個先驗**。

(c) **輸出**：孤島列清單、各組於各 Heading 群內之**連續段數**、
    孤島之**聚集分佈**。聚集本身為證據 —— 若切分照能力，
    錯誤應散開；聚於一段表示該段有系統性成因。

(d) **處置**：每個孤島列須有**記名依據**（記於 `framework.md`），
    且該依據**不得為其標題之關鍵詞與組名相符**
    —— 關鍵詞相符是循環，不是依據。
    無法給出記名依據者，標 `PROVISIONAL-ROW` 並取其
    `Requirement Description` 複核。

(e) **限度（須隨檢查一併陳述）**：孤島列指出「該處之依據需高於相鄰之
    先驗」，**不是「該處錯了」**。規格作者確有可能在連續數列中交替
    寫數種能力。判其對錯仍須讀該列之描述。

(f) **寫回前之要求**：Layer 2 進工作簿（R-SU18(b)），
    故 `PROVISIONAL-ROW` **不得帶入寫回** —— 寫回前須全數解除。
```

```
R-SU21（切分原則之射程與 0 列群之效力）

(a) **原則 2（跨章之 Heading 群必拆）之射程為 Heading 群，
    不比照 R-SU19 及於 Test Set。**

    理由與原則 4 不同：原則 4 之目的為 Test Set 之索引價值（規模），
    該價值由 Test Set 之規模決定，故其射程須及於 Test Set。
    原則 2 之目的為**揭穿「Heading 標題不描述其所轄」之上游文件缺陷**
    （`309`／`170` 之實證）；Test Set 為本案自行切分之單位，
    其跨章若出於「同一能力在規格中散於數章」，那是規格編排之事實，
    不是切分缺陷。IN §4.1.3 之判準為「filter 後是否得到有意義之叢集」，
    **不是「是否單章」**。

    據此 `Integrity Verification`（跨 `4.8.2`／`4.8.3`）**不拆**。
    **配套**：Layer 3 對此類組須列出其全部章，不得只列其一。

(b) **0 列 Heading 群之歸屬**：本案 45 群中有 8 群所轄 in-scope 列為 0
    （`016`,`017`,`020`,`022`,`072`,`073`,`074`,`076`）。
    其歸屬**維持**（供導航與群數閉合），但**不具交付效力** ——
    其歸屬在原理上不可被任何列證據支持或推翻。

(c) `framework.md` 須於 Layer 2 表中**標記該 8 群**並加註：
    「0 列群之歸屬依據為標題字面，無列證據，不具交付效力，
    亦不得作為其他歸屬之類比依據。」
```

## 五、Priority 之裁定

```
R-SU22（Priority 之來源與 037 Priority 欄之地位）

037 之 `Priority` 欄（`High` 271／`Medium` 34／`Low` 6／空白 72，
全 383 資料列）與工作簿 P 欄之 `P0`–`P3` **不作機械映射**。

理由：
(a) 037 之 Priority 為**需求級**之重要度，`P0`–`P3` 為 **TC 級**之
    測試優先序（IN §10.2 之 rubric 依 TC 所驗之行為判，
    如安全／開機／連線／音訊／關鍵 CAN 訊號）。二者之判準不同軸。
(b) 三值對四值非一對一，任何映射表皆為構造（違 §8.4.1）。
(c) `High` 271 列佔母體 87%，若映射為 `P0` 將使 P0 失去鑑別力。

裁定：
1. `priority` 一律依 **IN §10.2 之 rubric 逐 TC 判**。
2. 037 之 Priority **僅作參考訊號**，得記於 `reasoning`，
   **不得作為 P 值之唯一依據**。
3. 母體 311 列中 Priority 為空白者之列數須實測（T30b）；
   其空白**不影響本裁定** —— 因 P 值本就不由該欄導出。
```
