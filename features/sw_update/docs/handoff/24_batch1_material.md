## 三、R-SU30（新條，抄入 RULINGS.md，逐字）

```
R-SU30（滾動清單之讀法防誤）

DR-SU2 之清單為滾動式：初始 5 列，隨撰寫批次增列。
其誤讀之風險為 —— **「已在清單上」被讀成「已確認無解」**，
而 105 列中之其餘 100 列**尚未逐列確認其確無可觀測後果**。

裁定：凡滾動清單之台帳，其條目須分二段，且二段之語意逐次載明：

(a) **已確認段**：該列已由分析層逐列判定，其外部可觀測後果**取不到**。
    此段之列方為 DR 之實際標的。

(b) **未確認之母群**：符合同一語形條件但**尚未逐列判定**之列。
    其記法一律為「母群 N 列，已確認 M 列」，
    **不得只寫母群數而使人誤以為 N 列皆已確認**。

(c) DR 之 `Leaves served` 欄記 (a) 之列；`Batch impact` 欄得述 (b) 之母群，
    但須明記其**未經逐列確認**。

(d) 每包之未結 DR 清單須同時呈現 (a)(b) 二數，其比值即該 DR 之
    **確認進度**。進度為 0 之滾動 DR 不得被陳述為「已盤點完成」。
```

**據此 DR-SU2 之現況**：已確認段 **5 列**（`363`–`367`）／
未確認之母群 **105 列**（含該 5 列）→ 確認進度 **5/105**。
