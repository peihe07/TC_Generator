## 8. 獨立自評

### 8.1 §五.7 所問：T21a 之各式 regex 有無「命中了但不是自引」之偽陽性

**有，且三式全是。逐式如下：**

| 式 | 命中 | 偽陽性 | 偽陽性之樣態 |
|---|---:|---:|---|
| 式1 ObjectID | 14 | **0** | 無 —— 14 個 token 全數落在 487 物件之 id 集合內 |
| 式2 章節號 | 3 | **3（100%）** | `2.0`（2 次）、`1.2`（1 次）—— 皆為**版本號**，非章節號 |
| 式3 CFTS 字樣 | 0 | 0 | 無命中 |
| 式4 引號內章節標題 | 64 | **64（100%）** | 全為**彈窗名稱與 UI 字串**：`What's New`(12)、`ROV Forced Update Available B`(7)、`Conditions Not Met`(7)、`Update Now`(2)… |

**偽陽性之判別法為集合比對，不是判斷**：式1 比對 487 物件之 id 集合、
式2 比對 87 個章節號集合、式4 比對 87 個章節標題之逐字集合。
**凡不在集合內者一律判偽陽性**，不因「看起來像」而放行。

**式4 之 64 個命中全數落空，本身是一項有用的否定結果**：
037 之 Description 大量引用**彈窗名稱**（`What's New`、
`ROV Forced Update Available B`…），但**從不引用 CFTS 章節標題**。
即 037 與 CFTS 之連結不走「引述標題」這條路。

### 8.2 本輪之方法有無「答不到卻看似答到」之處

**有一處，且我認為它比上一輪那處更危險，因為它不需要任何人做錯選擇。**

**T21c 的散點與統計，讀起來像是在評價支柱 2 的可行性，而它答不到那件事。**

T21c 產出了 311 列的散點、違序率 0.546、LIS 62/311、Pearson −0.130 ——
**這些數字全部有效，但它們量的是「A 的首選之序位」，不是「真對應之序位」**。
A 尚未通過任何有效檢定（自證錨僅 2 列且同屬 4.12 區）。
故「序位近乎無關」這句話，**同時相容於「037 與 CFTS 順序本就不共軛」
與「A 的首選是噪音」**，本數據無法區辨。

下放包 §三 T21c 已明寫「只出數，不下判斷；此步驟明確依賴 A，已知非獨立」
—— **分析層已預先標明**。我照做了，並在 §3 再次標明。
但一份含 311 列散點、四個統計量、看起來很完整的節，
**其形式會壓過那句警語**。故本節於 §3 以區塊引言重述，
且**明文寫出「本輪之序位統計不得用以評價支柱 2 之可行性」**。

### 8.3 一項我做了但下放包未要求的事

T21c 只令輸出「違序對數與最長單調不減子序列長度」。我另測了
**最長單調不增子序列（34）與 Pearson／Kendall**。

理由：只給違序率 0.546，讀者極易讀成「略高於隨機，大致無關」，
而 0.546 也相容於「反向排列」（若為完全反向，違序率會是 1.0）。
補測不增子序列（34 < 62）與相關係數（−0.130）才能排除反向假說。
**單一統計量在此處會誤導**，故補之。
