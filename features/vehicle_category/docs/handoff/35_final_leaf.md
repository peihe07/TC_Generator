## 二、`065-02`：裁**佔位剝除之取材通則** —— 不是第四處置類

### 2.1 四候選之處置

| 候選 | 判 |

| 另立第四處置類 | **否** —— 為一筆立一類，且問題不在「指涉怎麼解」而在「標的夾帶什麼」|
| **剝除佔位後再取** | **採，但升為通則而非個案** |

### 2.2 關鍵：`066` 已經是先例

你們在 `066` 做的正是這件事 —— §3.4(d)：Description 含
`(image: image23.png)`，**上半取首句、不入佔位、第 7b 項通過**。
`066` 能自然做到，只因其佔位在句號之後，切分自動分開；
`065-02` 的佔位黏在句尾（引號後無句號），切分帶著它走。

**二者是同一件事的兩種黏法。** 通則化：

```
profile §9 取材通則（新增，適用於全部層次）：

`(image: imageNN.png)` 佔位為 SYS1 匯出之插圖標記，**不屬句子文字**。
任何層次之取材（整段／單句／首句），其標的一律**止於佔位之前**；
佔位不入 `test_item` 上半。

剝除後之上半仍須為來源之**逐字子串**（第 7b 項照驗，無豁免）——
佔位剝除只發生在**尾部**；佔位居中而剝除會斷開文字者，
不適用本條，停並回報。

先例：`066`（佔位在句號後，切分自然分離）；
本條使 `065-02`（佔位黏句尾）與其同一處置。
```

**「剝除後仍為逐字子串」是本條的安全鎖** —— 尾部剝除必然保住子串關係
（剩餘為前綴），機器照驗；居中剝除會造出來源沒有的相鄰關係，禁。
