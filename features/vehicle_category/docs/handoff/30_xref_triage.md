Pei 已確認 tsv 含每處提及之行全文 → **粗篩可在既有輸出上做，不重跑**。

### 2.1 粗篩之判準

A-VC20 之特徵：**同一標的、二處皆有內容性描述、而其一說「無」另一說「有」**。
可機械化者為前二項：

```
第一層 —— 剔除純引用型：
  該行提及該標的，但**不描述其內容**者剔除。特徵：
  (a) 純編號引用（「見 R-VC12」「依 DR-VC6」「同 §10.1」）
  (b) 清單成員（表 B 之 17 節清單、批次之 leaf 列表）
  (c) 交叉指涉（「其標的為 §15」）
  保留者：該行對該標的之**內容**有所斷言
  （「§10.1 含二句文字」「該節僅存於圖」「其 Description 為 X」）

第二層 —— 標記對立語彙：
  保留之候選中，同一標的之二處若分別含
  「無／未帶／僅存／不含／零」與「含／有／載／逐字為」之語彙者，
  另出一份高優先清單。
```

**輸出三份**：
- `xref_triage_pruned.tsv` —— 第一層剔除者（附剔除理由之類別 a/b/c）
- `xref_triage_review.tsv` —— 第一層保留者（人工讀之標的）
- `xref_triage_priority.tsv` —— 第二層標記者（**最可能為真牴觸**）

### 2.2 self-test 前置

```
(b) 已知標的 = §10.1 —— 其 DR-VC6 實測佐證欄（「含二句」）與
    R-VC12 二(a)（「未帶文字」）二處，**皆須落入第一層保留**，
    且**須落入第二層高優先**（對立語彙齊備）
(a) 反向 = 一個純編號引用行（如某處之「依 R-VC12」）→ 須被第一層剔除
```

**斷言不過不跑正式母體**（§7.1.1）。

### 2.3 偽陰性（須揭露）

- 語彙表列舉式，**同義而不同詞者抓不到**（如「該節為空」vs「未帶文字」）

  **R-VC12 二(a) 與 R-VC12 其餘各款就在同一個檔裡**，
  該類若再發生，本工具與其粗篩皆看不到
- owner 降噪 7/107 之限制不變

**本輪之產出仍不主張「已無牴觸」** —— 只主張「該讀的縮到可讀之數」。
