## 7. 量測條件揭露（R-G8）

### 通則

- Python 3.10、`openpyxl`（repo `.venv`）。xlsx 一律
  `read_only=True, data_only=True` —— 取快取值不重算公式。
  **偽陽性風險**：若某儲存格之公式從未被 Excel 計算過，快取為 `None`，
  會被誤判為空。本次三份素材之關鍵欄皆為靜態文字，無此風險；
  036 母本之 B 欄確為公式（`=IF(ISBLANK($D10),"",ROW()-9)`），
  但 B 欄不參與任何 T4 判準。
- 字串比對前 `strip()`，且 U+00A0 先轉半形空白再 strip。
- 集合比對為**逐字**：大小寫敏感，不正規化底線／括號／空白。
  **偽陽性風險**：若 037 與 SYS1 對同一章節採不同拼寫變體，
  逐字比對會判為未命中。本次命中率 66/66、未命中 0，該風險未實現。
- 雜湊一律 `shasum -a 256`；mtime 一律 `stat -f %Sm -t %Y-%m-%dT%H:%M:%S`。

### T4 專項

- **腳本**：`features/vehicle_category/scripts/t4_remeasure.py`，只讀不寫，
  30 項逐項輸出「下放包值 / 實測值 / = 或 ≠」，任一 ≠ 即 `exit(1)`。
  **本次 `exit(1)`。**

  A 欄（`SWE-Requirement ID`）非空者。

  格式列（至 198）」一致，`iter_rows` 共 198 列亦相符。
