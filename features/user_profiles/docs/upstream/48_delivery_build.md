## 10. 獨立判斷

1. **本輪最該記的一件事：閘擋了四輪，而它擋錯了。**
   42 輪之產出閘寫的是「值是不是 `None`」，而它要表達的是「決定了沒有」。
   44 輪決定了留空之後，**那個閘沒有變綠 —— 因為值仍然是 `None`**。
   48 包稱之為「分析層未同步收回封鎖」，而更精確地說：
   **是我把一個「狀態」寫成了「值的形狀」**，於是狀態改變時閘沒有跟著動。
   G-C 之 `{value, applied, why}` 正是為了分開這兩件事而立的（43 輪），
   **而我立了它之後沒有回頭改那個閘** —— 又一次「殘留」（47 輪 §7-1 之同型）。

2. **`\b` 對中文不成立這件事，暴露的是掃描之「量測條件」沒有被寫下來。**
   語料側掃描回報「命中 2」，產出側掃描回報「命中 3」——
   **兩個數字都是真的，差別在正則**。若當時只跑了語料側，
   `TC-082` 會帶著「未決」二字進交付件。
   建議：凡回報「命中 N」之掃描，其**正則本身**應與數字一併記入上繳
   （本輪 §2.2 已如此做）。**數字沒有量測條件就不是證據。**

3. **交付欄位淨化只做了 48 包點名的兩類，而 remarks 裡還有六類內部指涉（§2.3）。**
   我沒有擅自刪 —— 那是交付內容之實質變更。
   但請注意其規模：**59 條 remarks 帶 canon 節號、59 條帶內部掃描代號**。
   若客戶讀得到 remarks，這份文件會告訴他我們有 `X-1` 到 `AC-1` 這些掃描。
   **這不是洩密，但它是「內部工作痕跡」**，值得在送出前決定一次。

4. **12 條未覆核而已產出，這件事本身是對的，而它有一個前提要說清楚。**
   48 包之理由是「改一條之成本為重生成 ＋ 重寫回 = 0.04 秒」。
   **該成本估計只涵蓋機器的部分。** 每次重寫回會連帶：
   台帳新增一個 ENTRY、兩至三份 pack 過期重出、待判登記表重判數條 ——
   本輪即發生了三份重出與三次重判。
   **機器成本確實接近零，記錄成本不是。**
   建議：餘 12 條之覆核**一次讀完再一起改**，不要逐條落地。
