## 1. 作業 2 之意外收穫：**06 輪之定位器對兩節取錯了**

R-U34 之驗法為「取 xlsx 結尾句，查其是否出現於 PDF 次頁」。
**對照向（R-G7）先跑**：同一句查**本頁**，須全數命中。

| 向 | 結果 |
|---|---|
| **對照：結尾句命中本頁** | 131 / 139 |
| 次頁命中（＝跨頁候選） | **1**（`5.1`）|

**逐一追那 8 個未命中，`5.1` 之成因不是跨頁：**

```
PDF p6:  PRACC7.) On profile switch with an active navigation route - calculate
         a route on the new profile using the remaining waypoints…
PDF p7:  PRACC7.) When in the Profile section, there will be two tabs; "All
         Profiles" and "Edit Profile"…      ← 這才是 5.1 之內容
```

**`PRACC7.` 被兩個 outline 共用**（`4.7` 在 p6、`5.1` 在 p7）—— spec 跨章重用條款標籤。
06 輪之 `re.search` 取**第一個**命中，於是把 `5.1` 對到了 `4.7` 的條文。

**全量查重複標籤**：140 個標籤中 **3 個**於 PDF 出現一次以上 ——
`PRACC7.`（`4.7`／`5.1` 共用）、`CPA2.`（`11.4`，其一為 `Table CPA2.)` 之內含）。

**兩道修正已寫入 `scripts/audit_xlsx_vs_pdf.py`**：

1. 標籤須在**行首**（排除 `Table CPA2.)` 之內含命中）
2. 仍多於一處者，取**與 xlsx 文字相似度最高**之那一處（`difflib`，`autojunk=False`）

> **這個缺陷不是 R-U34 要找的東西，是找它的過程撞出來的。**
> 若沒有那道對照向（「結尾句該命中本頁」），`5.1` 只會是一個 +203 的
> 「其他不一致」，看起來像掉句 —— **而它其實是拿兩條不同的條文在比。**

### 1.1 其餘 7 個未命中，逐一具名（皆非掉句）

| 節 | 成因 |
|---|---|
| `3.1`–`3.5`（5 節）| xlsx 只有標題行，其「結尾句」即標題本身；PDF 中五表並排，該標題之排版位置不同 → **探針假陰性** |
| `8.7` | PDF 文字層有字內斷字（`spa ces`），逐字比對失敗 → **抽取層假陰性** |
| `9.2` | xlsx 與 PDF 之用字略異（`Stellantis Connected Account` vs `Connected Account`）→ 見 §4 之補句表 |

### 1.2 盲點檢查 —— 尾句法驗不到「連續頁也一起掉了」的情形

尾句法只驗**xlsx 有的句子**。若某條款跨頁**且其續頁部分也被 export 掉了**，
該法看不到。故另補一道**與 xlsx 無關**之檢查：

> 每頁文字是否斷在句中（結尾無終止標點）**且**次頁去頁首後以小寫續起。

**結果：0 / 20 個頁界命中。**

**兩種互不相關之方法皆為負** → 「條款不跨頁」之假設**成立**，
且此後是被驗過的，不是被斷言的。

## 2. 三個比率重報 —— **每個附其分子定義**（R-G8）

**共同分母**：140 節（標籤可於 PDF 定位者）／PDF 側字元總數。
**共同前提**：對照向（PDF 段落自比）差額全為 0 → PASS。

| # | 比率 | 分子之定義 | 節數比 | 字元比 |
|---|---|---|---|---|
| **A** | 無頁界切段 | 「自本標籤至**下一個標籤**」所得之段落與 xlsx 相異者。**把下一頁之頁首、圖說、表格算成本條之續文** | 24 / 140 = **17.1%** | 5,772 / 35,437 = **16.3%** |

| **C** | 逐條查證後之**真掉句** | 該節 PDF 側有、而**全 169 節之 xlsx Description 皆無**之片段 | **5 / 140 = 3.6%** | **651 / 31,630 = 2.1%** |

本輪依 outline 逐節計。**兩者皆非計算錯誤，是計數單位不同**（R-G8 之同一形態）。

**定位器修正對 A／B 之影響**：A 之字元比 16.8% → **16.3%**、
B 之字元比 6.3% → **6.2%**；**B 之 13 節清單完全未變**
