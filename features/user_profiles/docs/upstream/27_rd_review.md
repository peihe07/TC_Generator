## 1. X-1（必改）—— 附錄之 seven 與表列 4 條不符

### 1.1 事實

v1 附錄寫 `seven leaves … have Title values that are displaced`，其下只列 4 條。
**收件者會數到 4 而讀到 seven。** 27 包之判定完全成立。

### 1.2 處置：**採「列出全部七條」，並逐條標其是否錯置**

27 包給了兩個選項（列全七條／寫 `four of the seven` 並具名其餘三條）。
**採前者，但比它多一步**：七條全列，並分為兩表 ——

| | 條數 | 內容 |
|---|---|---|
| **Title 指向他 leaf 之 Description** | **4** | `125-03`／`125-04`／`126-01`／`126-02`，並逐條標明「那是誰的 description」 |
| **Title 與自身 Description 一致** | **3** | `125-01`／`125-02`／`126-03` |

**為何多這一步**：只寫「四條錯置」，收件者仍要自己去數另外三條是哪些、
是否也有問題。**把三條也列出來並說明它們沒問題，對方才不必回頭查。**

### 1.3 順帶更正一處措辭

三條「一致」者中，`125-01` 與 `125-02` 之 Title **只涵蓋其 Description 之一部分**
（`125-01` 之標題取的是其描述之**例外子句**，主句「只有 HVAC／Media 可用」未入標題）。

**這不是錯置**（主題確在自身描述內），但也不是全然精準。
v2 於該兩列加註「though it names only …」——
**對外文件不宜把「不完全精準」寫成「一致」而不加說明。**

## 2. X-2（必改）—— `shifted by one position` 是未經證明之模式

### 2.1 我同意，且該主張確實不成立

以七條實查，四條之取用方向**並非同一位移**：

| leaf | 其 Title 取自 | 方向 |
|---|---|---|
| `125-03`（12.8）| `126-01` 之描述 | 12.8 ← **12.8.1** |
| `125-04`（12.8）| `126-02` 之描述 | 12.8 ← **12.8.1** |
| `126-01`（12.8.1）| `125-02` 之描述（部分）| 12.8.1 ← **12.8** |
| `126-02`（12.8.1）| `125-03` 之描述（部分）| 12.8.1 ← **12.8** |

**兩組互相取用，不是單向的 +1。** 稱其為位移是我的推測，未經證明。

### 2.2 處置

- 刪去 `shifted by one position`
- 改為中性之 `the Title names a subject that belongs to a different leaf's
  Description`（事實）
- **另加一段明說我方不主張模式**：
  > We describe this only as a mismatch, not as a pattern. We have not
  > established that the titles are displaced by a fixed offset …
  > Whether this arose from a single editing operation is not something our
  > evidence can show.

**這一段比刪掉那句話更重要** —— 收件者若自己看出「像是位移」，
會想知道我方為何不說；明寫「我方之證據無法顯示」，
比留白更不容易被讀成疏漏。

### 2.3 連帶：內部檔之同一措辭

複核所得之描述，且該檔為內部記載（R19-2 之精神：已結輪次不回溯編輯）。
**惟若分析層認為內外應一致，我可於下輪加註**（不刪原文，另起一行註明
