# 55 下放包 — Test Item 之兩段結構：立規格、立閘、ENTRY 003

**本包無裁決條文。** Pei 已確認形態，**54 包之量測作業取消**（第 0、1 項不做），
改為直接立規格。

## 一、規格（Pei 2026-08-19 確認）

`Test Item` 欄之內容為**兩段**：

```
<標題>
(<簡短說明：本條在測什麼>)
```

- **第一段** —— 現行之 `tc_title`，形態不變（canon §4.3 三種形狀，2–14 詞）
- **第二段** —— 括號內，**一句簡短說明本條在測試什麼**

範例（`NR1L-UserProfiles-157`）：

```
Welcome popup shown at ignition on and on activation
(Verifies that a welcome popup is displayed both at ignition on
 and each time a Profile is activated)
```

### 1.1 第二段之撰寫規則

沿用既有之欄位紀律，**不另立新規**：

- **英文**（canon §1：TC workbook 欄位一律英文）
- **無 modal**（`shall`／`will`／`should`／`would`）—— 同 §6 之 ER 規則
- **無 §5.1 之禁用動詞**作主要動詞（`observe`／`check whether`…）；
  `Verifies that …` 之陳述句形式為許可
- **不捏造**（§8.4.1）—— 其內容須為該條 ER 之概括，
  **不得引入 ER 未斷言之事**
- **無行尾句點**（§11）
- **無方括號**（除 D-UP22-01 之 profile 例外）
- 長度：**一句**，建議 ≤ 25 詞

### 1.2 來源

第二段由該條之 **`reasoning` 之「驗證目標」句**改寫為英文，
**不另行構思** —— 該句本即「本條在測什麼」之中文陳述，
且已於全部 189 條存在。

**此為關鍵**：不是新增一段創作，是**把已有的東西搬到交付欄並譯為英文**。
故其正確性已由 189 條之覆核背書。
