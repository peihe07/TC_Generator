> **自我測試若以當前語料為案例，缺陷修好之後測試即失去證明力，
> 而它表現為分數下降 —— 看起來像判準退化，實際上是證明消失。**

57 輪實測：31 條一改寫，`10/10` 立刻掉到 `7/10`。
**正解為將原文以字面釘進測試，另加「修正後不得再命中」之回歸。**

G-K（報 0 命中前先證明它會叫）並列 —— **三者皆為「證據本身之有效性」**。
