### J-14 —— 「R-U5 之 rubric 無安全帶」為誤讀，該待裁項關閉

執行層自 17 輪起三度提出此項（17 §4-1、18、19 §7），
並於 TC-073 以「就近判」處理。**不需要就近判。**

R-U5 第二段逐字：「上調至 P0 僅限符合 §10.2 P0 條件者
（**安全**、開機／復原、連線、音訊輸出、車輛關鍵 CAN、資料遺失風險）」。
**安全就在裡面。**

R-U5 之「核心五類」是本 feature 主流程之**具體化，非窮盡**；
凡符合 §10.2 P0 條件者皆為 P0，不必迂迴經 D-UP16-01 之 tie-break。
TC-073（行進中 Valet 可被解除）依 §10.2 之「安全」直接成立 P0，
其 reasoning 之依據改記為 §10.2，不再寫「rubric 無安全帶」。

**D-UP16-01 之 tie-break 仍然有效**，其適用範圍為
「同時落在核心五類與邊界／非主路徑兩帶」者，與本項無關。
