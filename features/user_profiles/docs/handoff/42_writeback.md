## 二、兩項常規化（採 41 輪獨立判斷 2、3）

### G-A：待判之時效

> **同一條待判連續三輪判為「不成立」者，須改判準或除役，不得續留。**

理由（執行層之語）：**紅的東西會被修，綠的東西沒人看，
而待判的東西每輪被抄進上繳一次** —— PU0588 那兩處誤報就是這樣活了六輪。
R-G9 之「誤報之閘活不過三輪」原為**紅**而寫，本條將其擴及待判。

### G-B：枚舉型判準一律接對照

`STATE_VALUES`（寫死四個）與 `UI_LOCATORS`（寫死兩個）接上 **VB-2 同型之對照**：
以語料實際出現之值回頭比對清單，未入清單者掃描結果不予採認。

**`KNOWN_PU` 與 `DESIGN_METHODS` 為現測，不須。**
分辨依據為「該清單是寫死的還是量出來的」，不是「它有沒有出過錯」。

## 三、「180 / 180」之讀法（採 41 輪獨立判斷 4，記入 profile）

> 全覆蓋說的是**037 之每個 leaf 都有一條 TC**，不是「每個 leaf 都驗完了」。
> **覆蓋率是分母的性質，不是分子的品質。**

第六批即有四處於 remarks 具名「本條不保證」之留白。
交付說明如需引用覆蓋率，**須同時載明此句**，不得只給 180/180。
