### 三-1 判準（**圍籬優先於動詞**）

| 判 | 條件 |
|---|---|
| `mention`（不計 FAIL）| 落於 `「」`／`『』`／反引號／直引號／`“”` 之內；或落於 code fence 內；或落於 `[SUPERSEDED]` blockquote 區內；或窗內最近之標記為 `之條文`／`所述`／`該節`／`原文`／`提及`／`所指`／`字串`／`複寫` 等 |
| `use`（計入解析義務）| 圍籬外，且窗內最近之標記為 `依`／`照`／`違反`／`適用`／`豁免`／`見`／`據`／`按`／`依據`／`依照` |

**「圍籬優先於動詞」為本判準之關鍵**：誤踩之第 2 例其引號**內部**
就有規範性動詞（`「依 canon §8.7」`）—— 若以動詞優先，該例判為 use，
判準即對其成因無效。

## 四、§四 waiver 改內容雜湊為鍵

### 四-1 鍵與欄

```
舊：(source, line, kind, target)
新：(source, kind, target, line_sha8)      # line 降為輔助欄，不參與比對
欄：source  kind  target  line_sha8  line  reason
```

`line_sha8` = 該行內容去尾端空白後之 sha256 前 8 碼。

### 四-2 遷移

**577 列 → 456 列**（−121）。**其減少全數為 §三-3 之可撤列**（123 列，
另有 2 列因語料變動而移出），**非遷移損失** —— 遷移本身無損：
以 `--emit-waiver` 自現行語料重產，每一仍需之列皆得其新鍵。

**舊格式相容**：`load_waiver()` 偵測表頭無 `line_sha8` 時以 `legacy`
佔位載入，`waiver_hit()` 於新鍵未命中時 fallback 至 `(source, kind, target)`。
**遷移期之舊 waiver 檔仍可用**，已以測試釘住。

### 四-3 兩向測試（§四 所令，**兩向都要驗**）

| 向 | 測試 | 判 |
|---|---|---|
| **行移動不失效** | 於被豁免行之上方插入兩行，`--gate` 須 exit 0 且 `stale 0 列` | **綠** |
| **行內容變動即失效** | 同一行加一句補述，`--gate` 須 exit 1 | **綠** |
| 欄位形狀 | 表頭 = `WAIVER_COLUMNS`；`line_sha8` 為 8 位 hex；`line` 為數字 | 綠 |
| 尾端空白不影響雜湊 | `line_sha8(x) == line_sha8(x + "   ")` | 綠 |
| 舊格式相容 | 舊五欄檔仍命中 | 綠 |

**行移動不失效之字面案例即 26 上繳 §五-1 之兩次假性新增** ——
該形態自本包起不再發生。

## 九、獨立判斷 —— 本包是否仍有該驗而未驗者

1. **§八-1（下放包所問）：`gate_all` 之彙總邏輯本輪是否已在多支同紅情境實測？**

   **2 支同紅**（`canon_refs` ＋ `rulings_hash`，見 26 上繳 §五之輸出），
   其總判正確報「2 支未過」並列出二者之名。
   **惟該情境為偶發而非測試** —— `tests/` 內**仍無 `gate_all.py` 之單元測試**，
   其彙總邏輯（任一非零則總 exit 1、逐支列名）**沒有任何測試在管**。
   **這是本包新產之遺留項。**
2. **`mention` 判準會不會過度抑制？** 本包驗了四個範圍向（真正的援引仍判 use），
   **但未對現有 140 處 mention 抽樣人讀**，確認其中無「其實是援引」者。
   **判準之偽陰性未量。**
3. **waiver 之 456 列未逐列覆核其 reason 仍正確。** 遷移是機械重產，
   `reason` 由 `waiver_reason()` 重算 —— **若該函式之分類有誤，
   遷移會把誤分類一併帶過去**，且因總數下降而看起來像進步。
4. **`R-VF94` 之 sha 變動揭出 R-G22 與工具之語意落差**（§二之三條成因）：
   R-G22 說「條文」，工具量「錨點本體」。**本包只回報，未提修法** ——
   若要一致，須擇一：條文後之註記另立錨點，或 R-G22 改稱「錨點本體」。
5. **`IMPROVEMENT_METRICS` 之下一案量測點未指定執行者。** 本表令
   「每案結案輪同表追一列」，**但未說由誰追、於哪一步追** ——
   一個沒有人負責的量測點，其命運與本案之前四個未量指標相同。
