## 6. 獨立自評

### 6.1 §六-5：一個為了讓錯誤可被撞見而加長的文件，若因此使人讀得更少

**答：本輪之數據支持「加長是值得的」，但其理由不是加長本身 ——
而是那個要求把一件事從「寫結論」改成了「寫如何得到結論」，
而後者可以取代前者，不必二者並存。**

**(甲) 先給本輪之證據。** 新要求上線第一輪即抓到一個錯（54 → 41），
**而抓到它的不是分析層之閱讀，是我在寫導出方式時被迫回去看母群。**
**故其效力發生在「寫」的時候，不在「讀」的時候。**

**(乙) 由此得一個不加長的作法**：**不要「數字 ＋ 導出方式」並列，
而是讓數字之表述本身帶著母群。**

| | 長 | **短** |
|---|---|---|
| 舊 | 「54 條待裁」 | — |
| 新（並列） | 「54 條待裁（比對對象：…；母群：…）」 | — |
| **建議** | — | **「`kind==ruling` 中待裁 41 條」** |

**其字數與舊式相當，而母群已在句中。**
**寫不出母群的人寫不出這一句** —— **這正是要攔的那件事。**

**(丙) 故建議把 §三 #2 改為一句話之要求**：

> **凡報一個數，其表述須含其母群或其比對對象；
> 寫不進一句話者，該數尚未被導出。**

**(丁) 而有一類數仍須並列說明** —— **經更正之數**（如本輪之 54 → 41）：
**其價值在於記錄「錯過什麼」，而那是敘述不是統計。**
**建議：常態之數用 (丙)，更正之數用 §三 #2 之完整格式。**
