## §4　T3 —— I/O 母節 Revise（R-DIAG29）

母體：I/O 母節 **114** 個 037 列 → **160** 條 TC，其中含 `0x2F` 請求者 **127** 條 TC／**129** 處。
逐條表：`sandbox/r_diag29_revise.tsv`。

| 改法 | 處數 | 說明 |
|---|--:|---|
| 佔位型 → `03 <controlState for "…">` | **60** | `$ 2F 50 00 <buzzer control tone selection>` → `$ 2F 50 00 03 <controlState for "buzzer control tone">` |
| 長度軸 → `… 03` | **35** | 合法請求現為 `2F <DID> 03 <controlState>`，省末 byte 即 `2F <DID> 03`（R-DIAG22） |
| 值域軸 → `… 03 <out-of-range controlState>` | **34** | R-DIAG22(amend)：0x2F 值域軸保留完整長度、資料 byte 為越界值 |
| 描述行用詞 | **30** | `Send a write request for DID $50xx` → `Send an InputOutputControlByIdentifier request for DID $50xx`（`[A-DIAG68]`） |

**Control Enable Mask**：全 160 條 I/O TC 皆單參數 DID，**無一帶 mask**，合 R-DIAG29(d)。
