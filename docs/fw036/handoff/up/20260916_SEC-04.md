## 8　**升級項 —— framework Layer 2 名稱含 CJK，與 lint `K` 互斥**

### 8-1　事實

`framework.md`（**LOCKED 2026-09-16 (R-SEC10)**）之 Layer 2 名稱逐字取自 SEC-01 §5 案 A 表，
其中五個「未命名群」之名稱為**中文註記**：
`(非功能)`、`(環境)`、`(其餘)`、`(總則)`、`(IPC／JNI／IO)`。

batch 1 之 38 列中有 **10 列**落在其中兩個：

| Test Set | TC 數 | TC |
|---|---:|---|
| `(非功能)` | 9 | `NR1L-CP-011`~`-014`（CP-006 四 sibling）、`NR1L-CP-021`（CP-010）、`NR1L-KI-022`~`-025`（KI-012／013）|
| `(環境)` | 1 | `NR1L-SAM-001`（SAM-0002）|

`Test Set` 在 `K_FIELDS` 內 → lint **`K = 10`**（CJK 字元）。

### 8-2　為何不自行處置

- **改名** → 動 framework Layer 2 名稱，§0 明令「LOCKED 不動」、§7 列為升級條件。
- **照寫** → 中文註記會隨工作簿交付給客戶，且 `K` 恆為 10。
- 兩者皆需 Pei 裁，故**執行層不自裁**：本包**保留 LOCKED 名稱照寫**，`K=10` 如實回報。

### 8-3　分析層可考慮之三個方向（不擇一，供裁）

1. **補英文名**：`(非功能)` → `Non-Functional`；`(環境)` → `Environment`；
   `(其餘)` → `Others`；`(總則)` → `General`；`(IPC／JNI／IO)` → `IPC and JNI Interfaces`。
   走 R-G72 Revise 解鎖 framework。
2. **併入既有 Test Set**：例 CP-006／CP-010 併 `Client Interface`；KI-012／013 併 `Install State`。
   影響 leaf 數與 `layer2_assign.tsv`。
3. **`K` 對 `test_set` 欄於 Security profile 豁免**（比照 `I-cross` 之 `FEATURE_EXEMPT`）——
   **執行層不建議**：中文仍會進交付本，只是 lint 不報。
