### 5.1　R-CAM3 之判準張力（一併回報）

R-CAM3 逐字為「PROXI 前提值、**觸發訊號名**、或 ER 可觀察結果**任一**因車型而異 → 拆」。

PROXI 前提值或 ER 因車型而異者才拆。** 此即本批實際採用之一致判準。

### 5.2　`= 8 mph` 之邊界值換算（A-CA22）

`BRAKE_FD_2.VehicleSpeedVSOSig` 之 `SG_` 為 `(0.0625,0) [0|511.875] "Km/h"`，
`VAL_` 僅 `8191 "SNA"`（無列舉 label）。門檻以 mph 表示而訊號單位為 km/h：

```
8 mph = 12.874752 km/h，非 0.0625 之整數倍
raw 205 = 12.8125 km/h = 7.9614 mph   ← off-point（未達）
raw 206 = 12.875  km/h = 8.000154 mph ← on-point（首個 ≥ 8 mph 之 raw）
```

`NR1L-RVC-009` 以 205／206 為 off/on point，並於 `reasoning` 具名換算。
