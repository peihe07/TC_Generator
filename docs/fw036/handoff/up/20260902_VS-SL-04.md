### R1 —— 審閱 §2 R1 之證據本層已複驗

总控表 No.267 `AUX SWITCH Type` Atlantis 欄逐字為
`If AUX_Switch_Types is [Type1]), return value is 4. Else if AUX_Switch_Types is [Type2]), return value is 6. Else return value is 0.`；
`_vf230_proxi_values.json['AUX_Switch_Types']` = `{0: Absent, 1: Type 1, 2: Type 2}`。
`SWITCH 1–4` → `= 1 (Type 1)`，`SWITCH 5–6` → `= 2 (Type 2)`，
label 依 proxi_values 逐字（`Type 1` 含空格）。**54 列逐列帶 `proxi_added`（assert PASS）。**

### R1b —— 本層新增之判，請 Tier 2 追認

包內只給三值，惟實測有一類**不屬其任一**：FIP 列存在、條件明確可取值，
但 v3 之條件式解析器抽不出 term，致 v3 誤判「兩來源皆空」。
**若落 R3 將在 DR 中陳述不實**（該條件確實存在）。

唯一一名（3 列）：`Auto Fold Mirrors`，总控表 No.147 逐字
`If "Auto_Power_Folding_Mirrors" is "Present", return value is true. Other return values are false.`
—— 其為**引號式**（`is "Present"`）而非中括號式，`settings_lookup._parse_terms` 只認後者。
`proxi_values['Auto_Power_Folding_Mirrors']['1'] = 'Present'`，故可確值。
**證據不足者未擴用此判**（見下 `FIP_PARAM_NOT_IN_VALUES`）。
