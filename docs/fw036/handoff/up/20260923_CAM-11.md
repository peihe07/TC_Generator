## §4　結構性回報

1. **selfcheck 第 8a 項與 lint `P` 初次互斥** —— 8a 要求 PENDING 置於行首，
   `P`（R-1 v2(a)）要求 CAN 賦值行為 `Send CAN: <MSG>.<Sig> = <raw> (<label>)`。
   先改為 `1. PENDING: DR-CAM-f set X to Y` 時 `P` 由 0 升為 4；
   再改為 **賦值行維持 `= PENDING (<label>)` ＋ 說明移至 `a.` 子項**後兩者皆 0。
   **此調和形制建議入 profile**（本包未自行寫入，歸 Pei）。
2. **`-164`（`V2-448`）之 PROXI 參數名查無** —— `Steering_Ratio_Rack_Pinion_Type` 於
   Atl-Hi 三本 PROXI 掃描零命中；Pre-Condition 依 §8.7.5(e) 以來源措辭逐字書寫，
   **未標 PENDING**（其非缺值，而是參數名與 PROXI 表不同名）。若審閱認為應併入 DR-CAM-n，請指示。
3. **`-166`（`V3-285` 之否定側）之 ER 只判「不為 `Type_1`」** ——
   來源只給一個對映（`[15.5]` → `[Type_1]`），其餘 PROXI 值之對照無來源，不自造（§8.4.1）。
   此與 §1-2 所記之「查表對映全覆蓋」不衝突 —— 該原則適用於**來源已列出全部對映**者
   （`V42-326` 五項），本列之來源只列一項。
4. **`-161` 之 SNA 有兩層** —— `ASCM_Stat` 自身之 `VAL_` 即含 `15 "SNA"`（ASCM 產生），
   本列所驗為 **LVDS 側**之 SNA（HU 產生）。兩者同名不同源，reasoning 已具名以免誤判。
