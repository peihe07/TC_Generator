逐本讀 `docs/fw036/lint_reports/*_20260821.json` 之 `counts` 鍵集合：

```
AMFM              A B C D E F G H I I-sibling J K L M N          ← 無 P
PowerManagement   A B C D E F G H I I-sibling J K L M N P        ← 有 P
```

七本產於 **`P` 檢查存在之前**，其報告內根本沒有這一欄。
故「八本基線 `P` 對照向」之**改前值只有 1/8 存在**；
其餘七本之「改前」只能取自現跑之改前版程式（本包所做），不能取自基線報告。
