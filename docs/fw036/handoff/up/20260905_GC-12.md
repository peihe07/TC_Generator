### 1-2　成因（已定位到單一正則）

```python
RE_P_ASSIGNMENT = re.compile(
    r"\b[A-Z][A-Z0-9_]{2,}\.[A-Za-z][A-Za-z0-9_]*\s*(?:=|from\b|to\b)")
```

樣式配不到；`check_signal_line` 隨即於 `if not assignments: return out` **提早返回**，
一個 P 都不產生。實測：

```text

RE_P_ASSIGNMENT 對 'Send CAN: STATUS_BH_BCM1... = 2 (Ignition_Off)'          → True
RE_P_VALUE_FORM 對 前者                                                      → False
RE_P_VALUE_FORM 對 後者                                                      → True
```

### 1-3　影響（三項，皆須裁）

1. **GC-12 二-1 之驗收條件為空條件**。「P 預期降至 0 或只餘 bare」——
   轉換前後 P 對 bare 行皆為 0，**無法分辨「已轉換」與「未轉換」**。
   此即 A-VS106 之形態（檢查靜默失效，其輸出與通過不可分辨）。

   v3 期由 `RE_P3_BARE_ASSIGN`／`RE_P3_DOLLAR_ASSIGN` 承接，v4 期無人承接。
