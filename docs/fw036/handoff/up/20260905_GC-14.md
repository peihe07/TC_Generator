### 1-2　偏離一：`PROXI Foo == "x"` 依原實作**必然不報**（登 A-GC26）

審閱指定之正控樣本「賦值形態但兩式不中 → 應報」為 `PROXI Foo == "x"`。
實測**不報** —— 成因不在 fallback，在標準式正則：

```python
RE_P_PROXI = re.compile(r"\bPROXI\s+([A-Za-z][A-Za-z0-9_]*)\s*=")   # 原式
```

`\s*=` 會匹配 `==` 之首個 `=`，故該行被判為**合規之標準式**而提早返回。
**該正控依原實作必然失敗，且其失敗會被讀成 fallback 之問題。**
已加負向前瞻 `=(?!=)`；並以 `test_proxi_double_equals_is_not_the_standard_form`
兩向釘之（`==` 不中、單 `=` 中）。

### 1-3　偏離二：「同行有」過寬，留 5 處誤報（登 A-GC25）

依審閱字面實作後 P = **240**，殘餘 5 處皆為同一形態：

```text
3. STATUS_TELEMATIC.PowerSts_Telematic = 1 (Standby) is sent after the
   PROXI Switch_Off_Time value has elapsed          （列 90／91／93，er 欄）
```

該行之 `=` 屬 **CAN 斷言**，與 `PROXI` 無關；「同行有 `=`」因而成立。
判準改為 **「緊接 `PROXI` 之參數後」**：

```python
RE_P_PROXI_ASSIGN_SHAPE = re.compile(
    r"\bPROXI\s+\$?[A-Za-z][A-Za-z0-9_]*\$?\s*(?:==|=|is\s+set\s+to\b)")
```

即 `PROXI` ＋ 一個參數 token ＋ 運算子。條文以此式落檔（canon §8.7.5(i)、台帳 R-G70(i)），
審閱之「同行」措辭於條文內加註為**不採**。
