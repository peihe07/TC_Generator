### 3.2　PC 之改寫（R-DIAG28(c)）

原 PC 為條文複述（`The retries performed during the package select process are the result of …`），
**不是可建立之狀態**。改為 X65 之回應態，`pc_sources` 記流程圖 NOTE 行與節點：

- timeout：`The Sirius XM chipset does not return a PkgInd message within 600 ms to any of the three package select commands`
- 三碼：`The Sirius XM chipset returns Indication Code $03 to each of the three package select commands`
- 混合：`The Sirius XM chipset returns a different Indication Code to each of the three package select commands`

**碼值記法用 `$03` 而非流程圖之 `0x03`** —— R-DIAG28(c) 之例示以「如」起首，是形式之例而非逐字強制；
該 TC 之 `specification_reference` 為 CFTS004（書 `$03`），ER 亦書 `$03`，**一條 TC 內記法須一致**。
流程圖之 `0x03` 逐字保留於 `pc_sources` 與 `cip_mpfa_flowcharts.md`。

### 3.3　(b) 流程後續不入 ER

Validate 之 `0x10` → `Proceed to MPFA Select Process`、Select 之 `0x00` → `Store the OpCode …` → `CA Pellet Creation`：
**ER 只斷言本常式之 results 碼**（`71 03 03 0x <code>`），流程後續不在本 037 列範圍（§8.2.1）。錨記於 Remarks。
