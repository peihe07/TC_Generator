### 8.1　`NR1L-DIAG-102`（`-145` sequential clockwise routine，P0）

```text
Requirement or Design ID : SWE1-Diagnostics-145
Test Set                 : Buzzer Control
Test Case Priority       : P0
Design Method            : 功能測試 (Functional based ; no specific technique)
Vehicle Model (T..Z)     : 1 1 1 0 0 1 1

Test Item
  The Diag Service shall interpret the received DID 0x5000 (Buzzer Control) request and initiate
  sequential radio-controlled tone output to the speaker outputs.
  ($5000, sequential clockwise rotation with a 10 s hold per output)

Pre-Conditions
  1. The ECU is in the default diagnostic session
  2. The diagnostic tool is connected to the OBD-II diagnostic connector
  3. Security access 0x27 has been granted

Input Test Data
  NA

Test procedure
  1. Select a radio-controlled tone in the Buzzer Control DID
     $ 2F 50 00 <radio-controlled tone selection>
  2. Listen to the Front Left speaker output
  3. Hold for 10 s
  4. Listen to the next speaker output in clockwise order
  5. Hold for 10 s
  6. Listen to the remaining speaker outputs in clockwise order
  7. Disable the Buzzer Control DID
     $ 2F 50 00 <Tones Off option selection>

Expected Result
  1. The positive response 6F 50 00 is received
  2. The radio-controlled tone is output on the Front Left speaker output
  3. The tone is held on the Front Left speaker output for 10 s
  4. The tone is output on the next speaker output in clockwise order
  5. The tone is held on that speaker output for 10 s
  6. The rotation continues through the remaining speaker outputs and repeats
  7. The positive response 6F 50 00 is received, and the tone rotation stops

Specification Reference
  CFTS004-4940294
  CFTS004-4940295
```

**說明**：`Hold for 10 s` 依 **IN §8.7.5(e)** 獨立成步、ER 對應，未併入前一步。
「starting with the Front Left output」與「10 seconds」逐字取 CFTS004-4940295；
「continue indefinitely」譯為 ER 6 之 `repeats`（不寫「無限」以免無法判定）。
步驟 7 之停止用 `Tones Off`（CFTS004-4940294），故該錨一併列入並升冪。
兩個 `<…>` 佔位皆因 CFTS004 未載編碼（§3.1）。

### 8.2　`NR1L-DIAG-125`（`$5001` Front Left 象限 positive，P0）

```text
Requirement or Design ID : SWE1-Diagnostics-103
Test Set                 : Speaker Quadrant Selection
Test Case Priority       : P0
Design Method            : 功能測試 (Functional based ; no specific technique)
Vehicle Model (T..Z)     : 1 1 1 0 0 1 1

Test Item
  The Diag Service shall interpret the received InputOutputControlByIdentifier (0x2F) request for
  DID 0x5001 and extract the Front Left speaker output selection parameter.
  ($5001, Front Left speaker output selected)

Pre-Conditions
  1. The ECU is in the default diagnostic session
  2. The diagnostic tool is connected to the OBD-II diagnostic connector
  3. Security access 0x27 has been granted

Input Test Data
  NA

Test procedure
  1. Select the Front Left speaker output
     $ 2F 50 01 <Front Left speaker selection>
  2. Read the currently selected active speaker output
     $ 22 50 01

Expected Result
  1. The positive response 6F 50 01 is received
  2. The positive response 62 50 01 <speaker quadrant byte> is received, and the reported value is the
     Front Left speaker output

Specification Reference
  CFTS004-4940302
```

**說明**：四象限（FL／FR／RL／RR）在 CFTS004 各自成條（4940302／4940303／4940304／4940305），
即 **037 已分列之軸**，不再拆 sibling；區分 token 為象限名。
PC-3 為 R-DIAG13 之保守套用（`pc_sources` 記明）。
步驟 2 之讀回用 `22 50 01`（同節之 R/W 讀 `-047`），使 ER 可觀察 —— 若只送 `2F` 而不讀回，
ER 只能斷言 `6F` 正回應，無法證明象限真的切換。
