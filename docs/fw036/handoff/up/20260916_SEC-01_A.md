## 1　三-1　CS.212 直連判準改判 —— **11 列 → 7 列**

### 1-1　四列誤判之逐字覆核（審閱判斷成立）

| 列 | 命中所在 | 逐字 | 判 |
|---|---|---|---|
| `SWE1-LOGENC-002` | THEN | `3. THEN logdog could link to Log Encryption without link error.` | **連結／建置**斷言，`logdog` 為主詞 → 誤判 ✅ |
| `SWE1-LOGENC-003` | **無 WHEN/THEN 子句** | `1. LogEncrypt library should provide API for LogDog: encryptLogFile(const std::string& plainLogFilename, …)` | API **識別字** → 誤判 ✅ |
| `SWE1-LOGENC-004` | THEN | `3.1. THEN AES is used for symmetric encryption of log files.` | log 為**加密受詞** → 誤判 ✅ |
| `SWE1-LOGENC-006` | **THEN 子句無命中** | `3.1. THEN the feature generates unique symmetric key…`／`3.2. AND provides to user with encrypted data…` | 命中只在 GIVEN／WHEN 之 `getsslog` → 誤判 ✅ |

→ 四列皆為 log *encryption*，非 secure *event* log。**審閱 三-1 成立，全數採納。**

### 1-2　判準之實作（`build_trace_matrix.py` 之 `cs212_log_assertion()`）

- **子句範圍**：含 `WHEN`／`THEN` 字樣之行，或以 `3.x` 編號起首之行
  （037 以 1.x／2.x／3.x 編 GIVEN/WHEN/THEN，`3.x` 之 `AND` 續行仍屬 THEN 區塊）。
- **否定濾網**：命中落在 `Log Encrypt*`（元件名）、`encryptLogFile`／`plainLogFilename`／
  `protectedLogFilename`（API 識別字）、`log files?`（加密受詞）、`logdog could link`（連結斷言）內者不計。
- 大小寫維持敏感（審閱採 DECISIONS 6-10-d）。

### 1-3　現行 7 列（逐列附其命中子句；新增 `cs212_clause` 欄）

| SWE1 ID | 命中子句（逐字）|
|---|---|
| `SWE1-CertProvider-005` | `WHEN. Monitor system logs during verification.` |
| `SWE1-CertProvider-006` | `WHEN. Review the source code and logs.` ＋ `THEN. Code must follow Google Java Style Guide, and logs must align with Logdog requirements (Error-level only for defects).` |
| `SWE1-CertProvider-008` | `THEN. Confirm successful end-to-end verification through system logs (Logdog) for both client types.` |
| `SWE1-KeyInsyall-010` | `6.1. THEN the system must REFUSE the request and log a security violation.` |
| `SWE1-KeyInsyall-012` | `- THEN no SELinux denial logs (avc: denied) related to KeyInstall should be present.` |
| `SWE1-SAM-0004` | `3.1. THEN DebugAuth logs an error via logdog, which corresponds to fail reason` |
| `SWE1-SAM-0015` | `3.2. AND DebugAuth prints the log about sending message with sequence ID mentioned` |

**與審閱指名之 7 列逐列相符。**

### 1-4　**對審閱規則之一處回報（`[A-SE12]`）—— 規則文字與所列集合不一致**

審閱 三-1 之規則文字：「**只計 THEN／`3.x`／`THEN.` 子句內之命中**」。
惟其所列 7 列含 `SWE1-CertProvider-005`，而該列：

```
GIVEN. Device with network access and an ECU certificate containing a valid CRL Distribution Point.
WHEN.  The certificate is revoked at the source and the verification process is triggered.
THEN.  The system shall fetch the CRL into RAM, identify the revoked status, return the appropriate error, and clear the RAM buffer.
WHEN.  Monitor system logs during verification.          ← 唯一命中
THEN.  No CRL file I/O operations (write/save) shall be observed in the storage partitions.
```

**命中在 WHEN，兩個 THEN 皆無命中。** 逐字照「THEN only」會得 **6 列**而非 7。

本包取 **WHEN ∪ THEN** 以重現審閱指名之集合，理由：該列之觀察**手段**即 log 監看
（THEN 之 `shall be observed` 所指之觀察面），語意上確屬 log 觀察類。

> **兩解對 batch 無影響**：`CertProvider-005` 本就有 `Cert Val CS.98` 落點，
> 無論 `cs212_direct` 為 Y 或 N，其 `ccvr_batch` 皆為 1。
> 故本項**不阻本包**，只影響 `cs212_direct` 欄之值與 `ccvr_items` 是否含 `Secure Log CS.212`。
> 請分析層於 SEC-02 明示規則本意（THEN only → 6 列；WHEN∪THEN → 7 列）。

### 1-5　`SWE1-CertProvider-006` 之附帶疑義（不改判，僅提請覆核）

該列 GIVEN 為 `The Cert Provider source code and build environment.`，
THEN 為 `logs must align with Logdog requirements (Error-level only for defects)` ——
**是對 log 寫法之編碼規範要求，不是「有 log 被寫出／可觀察」之斷言**，
形態與審閱所剔除之 LOGENC 四列較近（皆以 source code 為受詞）。
審閱將其保留於 7 列內，執行層**照辦不自裁**，惟依 R-G11 具名此疑義。
若 SEC-02 決定剔除，7 列 → 6 列，**batch 仍不變**（CP-006 有 CS.98 落點）。
