   建議 GC-16 之前，工具端加一道保護（掃描範圍外之既有列自動保留）——非本包可改（`scripts/` 為 canon 面）。

   該範圍屬 GC-16，不該由 feature 包觸發。
3. **`sibling_no` 未直接取自 `sibling_plan*.tsv`**：改以「同 SWE1 內之舊 TC 號」作等價鍵
   （v08 之號本就依 `sibling_no` 產生）。三份 plan 檔之欄位形制不一（batch2 有 `ee` 欄、
   deferred 有 `artifact`／`requirement`），直接 join 需三套解析；等價鍵已由 §5-4 之 0 格差異
   與 §5-5 之連續性間接證明。若分析層要求直接 join，可補一支驗證腳本。

   四段全在 CP 之 TC，故六本相加 = `_all` = 4，無重複計。
