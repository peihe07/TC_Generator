### 2-2　要件切分（R-SEC23(b)）

- 有 `THEN` 者取 THEN 子句（LOGENC-001／002／004／005／007／008／009、SAM-0001／0019）。
- 有列舉項者每項一 TC（LOGENC-003、SWDL-001／002／005、ECUONLINE、DOWNLOADCERT_INTF）。
- 單句英文 VC 者整句一 TC（兩個 Binder 列、JNI、STORAGE_IO）—— **未**把
  `correctly converted … without memory leaks` 切成兩件（同一 THEN 句，切開會使引文不成句）。
- `LOGENC-004` 之第 2 sibling 取 VC **末句**（`LogEncrypt feature uses OpenSSL library primitives for
  generating unique AES-256 symmetric keys to encrypt log files`）—— 其在 THEN 之外，
  但為可獨立審查之要件，`rule` 欄記 `VC trailing sentence (independent requirement outside THEN)`。

## 五、§0 第 4 條之列表（§4-5）

### 5-1　可執行觀察之掃描（19 列之 VC 全文）

比對式：`\badb\b|logcat|openssl|\bUDS\b|/(data|vendor|mnt|system)/|22 F1|31 01|pytest|am instrument`

|---|---|---|---|
| 1 | `SWE1-LOGENC-004` | `LogEncrypt feature uses OpenSSL library primitives for generating unique AES-256 symmetric keys to encrypt log files` | **非可執行觀察**：`OpenSSL` 在此為**程式庫名**，非 `openssl` CLI 之調用；該 VC 之結構為 `GIVEN Log Encryption source code / WHEN … / THEN …`，受詞是原始碼，無指令、無輸出斷言。故照文件審查產出；**列此備裁** |
