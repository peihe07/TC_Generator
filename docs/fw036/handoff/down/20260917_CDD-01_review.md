### 3-2　R-DIAG5(c) 適用空白（up §7-1、§9-3）—— 建議 **(甲)＋(乙′)**

事實確認：CFTS004 只在 5 處給 NRC 值；037 定型句 205 列不帶值；`0x2F` 三方只 037 載。
依 R-DIAG5(c) 字面全部 PENDING → 230 列 negative／unsupported 無法產，等於 58% 的 037 列阻斷。

建議條文（`R-DIAG5(amend)`，Pei 裁）：

```text
R-DIAG5(amend)  SID／NRC 值之來源層級
  (c′) SID／NRC 值依序取：CFTS004 原文 → 037 Description／Title 明載值 → ISO 14229-1 標準碼。
       三者衝突時前者優先。
  (d)  取 ISO 14229-1 標準碼者，限下列五碼且只在 037 已述其失效型態時使用
       （IN §8.4.1 domain constant 條；CFTS004 自身以 $22／$31 引用同一標準）：
         0x11 serviceNotSupported            ← 037「Service Not Supported」
         0x12 subFunctionNotSupported        ← 037「unsupported sub-function」
         0x13 incorrectMessageLengthOrInvalidFormat ← 037「invalid length / incorrect format」
         0x22 conditionsNotCorrect           ← 037「conditions not correct」
         0x31 requestOutOfRange              ← 037「unsupported DID / out of range」
       label 用 ISO 名稱；Remarks 註 `NRC per ISO 14229-1 (037 unspecified)`。
       037 未述失效型態者仍 PENDING: DR-DIAG-1。
```

(乙′) 與執行層之 (乙) 差別：不是開放 ISO 全表，而是**封閉五碼＋須 037 已述型態**，
造值面積可控；且五碼皆為 UDS 通用常數，與 §8.4.1 之 `HTTP 200 OK` 同級。
准後 DR-DIAG-1 降為非阻斷（只餘 037 連失效型態都未述之列），FB-DIAG-e 仍送 Nik 於下版根除。
