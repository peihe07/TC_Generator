## 三、lint 缺口（SEC-04 修）

`SC` 第 4 判項（「ER 引用之指令未出現於同編號步驟」）**未抓到**上表前兩處：其比對只認 `$ …` 形式，而 ER 內指令為散文形式（`The adb shell ls -l … output`）。
修法：ER 行之指令抽取改為 regex `\b(adb( shell| pull| push| logcat| reboot)?|openssl|od|ls|cat|pytest)\b[^"]*`，取首個動詞 token ＋ 第一個非選項參數，與同編號 Procedure 之 `$` 行比對；不符者 FAIL。回歸三路徑 sha 不變；對 pilot02 重跑預期 `SC = 2`（即上表前兩處），修後 0。
