## §2　R-SEC5(a) amend 修正 —— [A-SE12] 結案，命中 7 列改 **5 列**

- `CertProvider-005`：`Monitor system logs` 在 WHEN，THEN 為「No CRL file I/O operations … shall be observed」—— 是檔案 I/O 之否定觀察，**非資安事件之 log 記錄**；且 CS.212 十三類無一對應「撤銷清單不落地」。**不計。**
- `CertProvider-006`：THEN「logs must align with Logdog requirements (Error-level only for defects)」—— 是 logging **規範**（等級政策），非「有事件被記錄」之斷言。**不計。**

判準補述第二句改為：「該 THEN 須宣稱**某一資安事件**（驗證失敗、未授權存取、狀態變更、提權、輸入驗證失敗等 CS.212 類別）**被寫入 log**，並可以 logcat／Logdog 觀察到；logging 政策、log 檔案處理、非事件性之 I/O 觀察不計。」

命中 = **CertProvider-008、KeyInstall-010、KeyInstall-012、SAM-0004、SAM-0015**。
CP-005／006 之 `ccvr_batch` 不受影響（二者經 SYS2 落 Cert Val CS.98，機械判準已為 1）；`batch_order.tsv` 之 `ccvr_items` 對此二列移除 `Secure Log CS.212`。**batch 1 仍 49。**
