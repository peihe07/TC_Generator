## 〇、裁定使前提翻盤 —— 先報結論

依 Pei 之裁定去查 037 SWRA `Analysis Report` 之 **D（需求分析全文）／H（可行性）／
I（分析意見）／Q（Verification Criteria）／R（Verification Method）** 五欄後，
發現 **VS-CF-02 §一與 VS-CF-01 之整條推論鏈建立在一個未經查證的前提上**：

> 037 D 欄逐字：「\*HW supplier shall notify the `$FR_VS_RQ_TGW$` and `$VentedSeatFR$` signals
> **via the VHAL interface**. \*CarPropertyService shall receive … send that to CarPropertyManager
> **via Interface**. \*CarPropertyManager will expose that value to HMI layer **via API interface
> as get/set methods**.」（`SWE1-VC-RightFrontVentedSeat-030`）
>
> I 欄逐字：「… sending **API** `$FR_HS_RQ$` command as request to ECU is feasible」
> （`SWE1-VC-RightFrontHeatedSeat-030`）

即 **`$FL_HS_RQ$`／`$FR_HS_RQ$`／`$FL_VS_RQ_TGW$`／`$FR_VS_RQ_TGW$`／`$HSW_RQ_TGW$`
是 VHAL／CarProperty API 層之訊號，不是 CAN 訊號。**

因此：

1. 工作簿把它們對映到 `TELEMATIC_VEHICLE_SETUP3.*_Tlm` 並以 bus trace 驗證，
   **是前手作者之自行解讀**，037 未如此指示。
2. **DR-15「請求訊號之編碼待覆」問錯了對象** —— 它拿 DBC 的位寬去問一個不在 DBC 上的訊號。
   「1 bit 載不動四值」這個矛盾是對映錯誤造出來的，不是規格缺陷。
3. **VS-CF-02 §1.1 之 5 列（71／86／157／172／233）以 `*_Tlm = 1 (Pressed)` 填實 —— 撤回。**
   那是同一個誤映的延續，只是把模糊值換成了具體的錯值。
4. **VS-CF-02 §1.2 之「B6-value-absent，1 bit 載不動四值」—— 撤回。** 理由同上。

⚠ 本項可能波及本包範圍外之 44 列 IMPL_GAP（`TELEMATIC_VEHICLE_SETUP.FL_HS_Cmd_Tlm` 等
「DBC 查無」之列）—— 若那些同為 API 層訊號，則「DBC 查無」本身就不是缺陷。
**本包不處理，另立量測工項（§四）。**

## 六、分析層自報（A 系列，次一未佔號）

**A-{n}　未讀 037 之 D／Q／R 欄即以 DBC 為唯一來源，連續三包**
- VS-CF-01 §一：以 DBC 位寬立 `R-VS102(1)(2)`，其中 (2) 之 5 列判「無可送之無效 raw」。
- VS-CF-02 §1.1：以 `VAL_ 0 Not_Pressed／1 Pressed` 填實 5 列。
- VS-CF-02 §1.2：以「1 bit 載不動四值」判 5 列不生成，並據此寫 DR 草稿。

三者皆未查 037 之 D 欄（需求分析全文）與 Q／R 欄（RD 已寫好的驗證判準），
而 IN §8.7.5(a) 明列**需求主體 = CFTS**、R-VF13 明列 **037 之 Q／R 欄為值域來源鏈第 4 順位**。
來源鏈中排在 DBC 之後、但**用途不同**的一份文件，被整條略過三次。

成因：DBC 是機器可讀、grep 得到的，037 之 Q／R 是自然語言欄位 ——
**選了容易量測的來源，而非該用的來源**，且未在任一包中聲明「037 未查」。
這與 A-VS45／丙-2 之「先斷後量」同族，但更嚴重：那些是量錯，這是**量了不該只量的那一份**。

**連帶影響**：`R-VS102(2)` 之條文（「訊號之 DBC 值域全數落在有效集內 → 不生成」）
其 5 個用例（row 64／80／151／166／225）**亦未查 037**。該條可能同樣建立在誤映上。
**請 Pei 裁是否併入 §四之量測工項一併複驗** —— 若那 5 列之 `*_STATSts` 確為 CAN 訊號
（它們是 CSWM 送出之狀態訊號，與 `$*_RQ$` 請求訊號不同層），則 R-VS102(2) 成立不受影響；
但這句話本身現在也只是推斷，未量。
