### 1.2　DR 結案／更新

```text
DR-SEC-n  CDD  → 降級為「CDD 實作本」：DID 定義以 CS.00102 SWAD SYS2 為準（`SYS-RA-CS00102-nnn`）；
          CS.00102 多處明寫 "Supplier shall communicate to Diagnostic Specialist solution defined to match with CDD"，
          實作選項（2955+295D+295E vs 295F；2965 長度 1000 vs 2048）仍需 RD 確認 → DR-n 保留，範圍縮為此二項。
DR-SEC-p  2951 語意 → 結案：CS.00102 無 0x2951；R1L SWQT 之 2951 = Software Inventory；CCVR `DID CS.102` 之
          「2951 Certificate Store UUID」為該 sheet 自填，不見於 CS.00102。Cert Val 第 1 項改以 2955／295D／295E 為 DID 面，
          Certificate Store UUID 之定義指 SD.00045。CCVR sheet 之 2951 列登 ANOMALIES 回饋 RD。
DR-SEC-o  FF02 兩態 vs 四態 → 保留；CS.00102 無 FF02，為供應商自訂 DID，NR1L 之回應格式需 RD 給。
          另：R1L SWQT 之 `FF01` SSN 在 NR1L 為 RID（Check Programming Dependencies），**NR1L SSN DID = `0x2975`**
          （CFTS004 `SYS-RA-DIAG-008`：HU ID (SSN)，NA 內部工程用）。SEC-01_C §3 之 FF01 列作廢，以 2975 為準。
DR-SEC-l  0x31 01 F0 00 → 部分結案（見 1.1 F000 列）；回應碼表待解圖。
DR-SEC-k  0x9001／0x9003 → 保留；CS.00102 查無，屬 MD 內部金鑰佈建規格。
DR-SEC-m  CS.00165 §5.6／SD.00125 §5.1 DTC 碼 → 保留；本資料夾 CS.00099 為 DTC 規格但 grep 無 U3033／CS.00165 條目，
          執行層以 `Analysis Report` 全表再查一次回報。
```
