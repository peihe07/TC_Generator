### 2-1. M7 引號（`label_quote_plan.tsv` 七問）

判準一句：**指涉畫面上可按／可讀之那個元件 → `"…"`；指涉系統狀態 → 不加**。

1. `The X airflow mode is active`：X 為狀態 → **不加**（91 列維持 state）。
2. `read the "RECIRC" state`：指按鈕 → 加引號；同型未引號者統一為 `read the "RECIRC" button state`。
3. `Set RECIRC to …`／`Change RECIRC` → label，加引號。
4. `Set the airflow mode to Face` → 改為既有句型 `Select the "Face" airflow mode`。
5. `Sync`／`SYNC`：依 R-C2 取 SR24 拼寫；執行層先量 SR24 export 中兩種拼寫之次數與所在句，**取條文用於按鍵標籤之那個**，全本一致。
6. `AUTO pop up` → verbatim，不動。
7. Tri-Mode `MODE` 等 → 本輪不擴。
