## §2　DID／RID 步驟定式（Pei 裁，取代 SEC-01_B §3 末段之 DECISIONS 待定項）

前例本 `SW Test Desgin_$22_Read_Data`／`$2E_Write_Data`／`$31_RoutineCtrl`／`$27_Security` 各 sheet 之步驟結構一致：
前提列狀態 → 步驟只送 bytes → ER 只寫回應 bytes（NRC 亦為 bytes）。轉為 FW036 英文寫法，依 IN §5.4 兩行式：

```text
R-SEC{live+5}  DID／RID 步驟定式
  (a) Procedure 步驟：
        n. Send UDS request <SID name> for DID <$XXXX> (<DID name>)
           $ 22 XX XX
      寫入：`Send UDS request WriteDataByIdentifier for DID $F18C (ECU Serial Number)` ＋ `$ 2E F1 8C <15 bytes>`；
      Routine：`Start routine <RID> (<name>)` ＋ `$ 31 01 XX XX`。
  (b) ER：`Positive response is received: 62 XX XX <payload>` 或
          `Negative response is received: 7F 22 <NRC>`；payload 之語意另起一行（例 `00 = INSTALLED`）。
  (c) Session 前提入 Pre-Condition：`Diagnostic session is <Extended (03) | SystemSupplierSpecific (60)>`；
      切換 session 之步驟 `Send UDS request DiagnosticSessionControl` ＋ `$ 10 60` 為 §5.3 常數候選 `ENTER_SUPPLIER_SESSION`。
  (d) 工具：以 bytes 為準，不綁工具語法；`NR1L_UDSTool`／RAFT 之操作方式不入步驟正文，可入 Remarks。
  (e) DID 值來源標記：值取自前例本者，Remarks 寫 `DID value per R1L Diag SWQT (SWTD-IF-DIAG-xxxxx); NR1L CDD pending (DR-SEC-n)`；
      CDD 到手後依 R-G72 發 Revise 本更新。
```

## §4　新增 DR

```text
DR-SEC-o  KeyInstall 安裝狀態之對外表示：DID 0xFF02 兩態（00 已裝／01 未裝）vs 037 KeyInstall-006/011 四態
          （NOT_INSTALLED 0／VERIFICATION_REQUIRED 1／INSTALLED 2／ERROR 3）。NR1L 之 DID 回應是否改為四態、
          或四態僅存於 secure partition 之 installstate 檔而 DID 仍兩態。
          影響：KeyInstall-011 之 ER（`getStatus()` 經 Binder 回 `INSTALLED (2)`／`ERROR (3)`）與 DID 讀值之對應行。
DR-SEC-p  DID 0x2951 語意：R1L Diag SWQT = Software Inventory；CCVR DID CS.102 = Certificate Store UUID。
          影響：Cert Val 第 1 項「列出 prod certstore」之 DID 步驟、CertProvider-007/009。
```

## §5　VHAL User Guide 之限定用法

只用於 **SAM-0013**（boot／resume 時通知 OFF）與 **SAM-0017**（IGN ON 時 seqId 歸 0）之觸發步驟，作 VHAL→CAN 之合法橋（規則：VHAL 層訊號不是 CAN 訊號，不得直接以 VHAL property 名寫 `Send CAN:`）：

| VHAL property | CAN 訊號 | 訊息／CAN ID／通道 | 037 |
|---|---|---|---|
| `IGNITION_STATE` (0x11400409) | `CmdIgnSts` | Atl-Hi `BCM_FD_10` 0x481 (AH_FDCAN8)；Atl-Mi `STATUS_BH_BCM2` 0x46C (AH_BHCAN2) | SAM-0013/0017 |
| `POWER_MODE_STS` | `PowerModeSts` | `BCM_FD_9` 0x42A (AH_FDCAN8) | SAM-0013（resume from suspend） |

步驟寫法沿 §8.7.5(c)：`Send CAN: BCM_FD_10.CmdIgnSts = <raw> (<DBC VAL_ label>)`；raw／label 逐字取 `forms/` DBC（R-7、R-17），VHAL Guide 只定訊號名與通道。Atl-Hi／Atl-Mi 訊息不同 → 依 R-CAM{live+2} 同型拆 sibling，Vehicle Model 各勾。
其餘五本 037 **不引用** VHAL Guide。
