# 下放／上繳 交換協定（Pei 2026-09-02 指示）

目的：Pei 只說兩個字。分析層與執行層以固定目錄交換，不經聊天貼文。

## 目錄

```
docs/fw036/handoff/down/   分析層（Tier 2）寫下放包
docs/fw036/handoff/up/     執行層（Tier 1）寫上繳包
```

## 檔名

`<YYYYMMDD>_<PKG-ID>.md`，例 `20260902_VS-SL-02.md`。
上繳包與其對應之下放包**同名**，放 `up/`。
附件（tsv／json）與該包同前綴，例 `20260902_VS-SL-02_alias.tsv`。

## 「下放」（Pei 對執行層說）

執行層：
1. 列 `down/`，取**最新之尚無同名 `up/` 檔**者為本次任務（通常只會有一個）
2. 讀畢後照包內 §「執行層任務」做；產物之落點依包內指定（多在 `features/<slug>/…`）
3. 完成後寫 `up/<同名>.md`：包內指定之上繳內容＋產物路徑＋SHA256＋自檢結果＋自報錯誤
4. 不動 `down/` 內任何檔

## 「上繳」（Pei 對分析層說）

分析層：
1. 列 `up/`，讀**最新且尚未審閱**之檔（審閱檔名為 `down/<同名>_review.md`，有即已審）
2. 審閱結果寫 `down/<同名>_review.md`；若需再下放，另開新包 `down/<新日期>_<新ID>.md`

## 寫檔驗證（分析層之硬規）

MCP 寫檔後必 `get_file_info` 核 mtime 與大小；未核不得聲稱已下放。

## 文面引用（2026-09-02 增，VS-SL-03 審閱；2026-09-02 第三增補強）

包文面引 canon 一律帶文件前綴（`FO §x`／`IN §x`），不寫裸 `§x`——
裸節號會被 `gate_all.py` 之 `canon_refs` 判為歧義。
**前綴不得憑記憶配**：引用前實測該節號在哪份 canon（A-VS169 與 VS-SL-06 §5-3 為同類二犯之鑑）。

## 目錄唯讀（2026-09-02 第二增，VS-SL-05 上繳 §6-2 之後）

`down/` 與 `up/` 對雙方皆為**唯讀之歷史紀錄**（各自只新增自己之包與審閱檔）：
任何量測、統計、暫存**不得移動、改名或覆寫**其中任何檔。
量測需暫存時一律 copy 至工作區，且以來源目錄分層存放，禁止扁平混名。

## 既有之 `docs/fw036/handoff/NN_*.md`

保留，不搬。自本協定起新包一律入 `down/`／`up/`。
