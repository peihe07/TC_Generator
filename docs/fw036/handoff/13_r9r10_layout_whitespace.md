## R-10 空白與字元正規化

```
R-10 正規化範圍依欄位分區
(a) 全欄位一律正規化（含 verbatim 上半）—— 不可見字元不構成內容：
    NBSP `\xa0` 與全形空格 `\u3000` → 半形空格
    行尾空白 → 刪除
    編號後空白 → 單一半形空格
(b) 作者生成之欄位（pre／input／proc／er／spec 與括號下半）另適用：
    彎引號 `“ ” ‘ ’` → `"`（§11）
    方括號 `[x]` → `"x"`（§11）
    行尾句號 → 刪除（§11、N-1）
    破折號 `–`／`—` → `-`
    連續 2+ 空格 → 單一空格
    標點前空格、括號內側空格 → 刪除
(c) verbatim 上半**不適用** (b)：其引號、方括號、句號、破折號
    屬來源原文，改之即破壞可回指性（R-6 理據）。
    lint 之 F（方括號）／N（句號）檢查不得施於上半。
```
