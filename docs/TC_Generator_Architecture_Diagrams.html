1. System architecture overview

Three-tier system: React Win95 desktop frontend, FastAPI backend (with SQLite job persistence), and OpenAI API (GPT-4.1 / GPT-5 family, with automatic prompt caching).

2. User workflow — window-by-window flow

Seven windows in the Win95 desktop. Each window is independently openable; the numbered path is the primary workflow.

3. SSE streaming and API data flow

All long-running operations use Server-Sent Events. jobAdapter.ts orchestrates calls and exposes typed callbacks.

4. TcRow status state machine

Each row in useJobStore.tcRows follows this lifecycle. Actions in Review Window drive transitions.

5. Store state and key types

useJobStore (Zustand) is the central data bus. All modules read from and write to it.
